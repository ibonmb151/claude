Conectar con cTrader

Qué es cTrader y cuatro formas de que un programa, o un agente de IA como Claude, hable con tu cuenta. Primero, cómo funciona sin tecnicismos. Después, la implementación correcta y lo que hay que vigilar.

Septiembre de 2026 · 12 minutos de lectura

5MM · 05 · 2026

En corto

  • cTrader es una plataforma de trading que Spotware licencia a brókeres y firmas de fondeo. Tiene cuatro puertas: la Open API para programas propios, FIX para sistemas institucionales, los cBots que viven dentro de la plataforma y MCP para agentes de IA como Claude Code.
  • La combinación sensata: estrategia y límites de riesgo en código determinista, con un cBot o un servicio sobre la Open API, y el agente de IA conectado por MCP para leer y analizar, sin permiso para operar.
  • Los sistemas se rompen por las reconexiones, las órdenes duplicadas, las unidades mal convertidas y los permisos caducados, más que por la estrategia. Todo eso tiene solución conocida.

Punto de partida

Qué es cTrader

cTrader es una plataforma de trading: el programa con el que ves precios y gráficos, envías órdenes y automatizas estrategias. La desarrolla Spotware Systems, una empresa fundada en 2010 en Limasol (Chipre), que lanzó la primera versión en 2011.

La plataforma no es el bróker. Spotware licencia cTrader a brókeres como IC Markets, Pepperstone o FxPro y a firmas de fondeo, que la ofrecen a sus clientes. Tu dinero, los precios que te dan y lo que te cobran dependen del bróker; el programa es el mismo en todos. Pasa como con los cajeros automáticos: la máquina puede ser idéntica en varios bancos, pero la cuenta y las comisiones son de cada banco.

Aplicaciones

Windows, Mac, web y móvil

Todas con el mismo usuario, el cTID, para cualquier cuenta y cualquier bróker.

Servidores

cServer

El servidor de cTrader de cada bróker, donde viven las cuentas y las órdenes. La infraestructura de Spotware está en los centros de datos Equinix LD5, en Londres, y NY2, en Nueva York.

Automatización

cTrader Algo

Robots (cBots), indicadores y plugins en C# o Python, con backtest y optimizador. Nació en 2011 con el nombre de cAlgo.

Copia y tienda

cTrader Copy y cTrader Store

Copy trading integrado desde 2018 y, desde diciembre de 2025, una tienda de cBots, indicadores y plugins de terceros.

Lo que puedes operar depende del bróker: divisas y CFD sobre índices, materias primas, acciones o criptomonedas. Usar cTrader es gratis; pagas los spreads, las comisiones y los swaps del bróker. Su gran competidor es MetaTrader 4 y 5, de MetaQuotes, que se programa en su propio lenguaje, MQL. cTrader usa C# y Python, y ganó terreno entre las firmas de fondeo cuando MetaQuotes les retiró licencias en 2024, como cuenta el documento 4.

Sin tecnicismos

Cómo funciona una conexión

Una API es una ventanilla para máquinas. En lugar de pulsar botones, tu programa envía peticiones escritas, como «compra 0,1 lotes de EURUSD con un stop a 20 pips», y recibe avisos, como «orden ejecutada a 1,1025».

Para usar la ventanilla hacen falta tres cosas. Tu programa se registra, como una empresa que pide una tarjeta de acceso. Tú, como titular de la cuenta, le das permiso para ver o para operar, igual que autorizas una aplicación en tu banco. Y la línea se mantiene abierta: cada diez segundos tu programa dice «sigo aquí» para que no le cuelguen.

MCP es otra cosa: un enchufe estándar para agentes de IA. El agente ve un menú de herramientas, como «consultar saldo», «ver precio» o «abrir posición», y decide cuál usar a partir de lo que le pides con palabras. cTrader ya incluye su propio servidor MCP, dentro de lo que llama AI Agent Connect.

Seis palabras que vas a ver

cTID
Tu usuario de cTrader, el mismo para todas tus cuentas y brókeres.
Aplicación
El registro de tu programa en cTrader. Recibe un identificador y un secreto, que funcionan como el usuario y la contraseña del programa.
Token de acceso
El permiso que das a esa aplicación para ver tus cuentas o para operar en ellas. Caduca a los 30 días y se renueva.
Protobuf y JSON
Dos formatos para escribir los mensajes: uno compacto, pensado para máquinas, y otro que una persona puede leer.
Latido
El «sigo aquí» que tu programa envía cada diez segundos. Sin él, cTrader cierra la conexión.
MCP
Model Context Protocol, un estándar abierto para conectar agentes de IA con herramientas externas.

Las opciones

Las cuatro puertas

Programas propios

Open API

Una ventanilla para programas escritos en cualquier lenguaje. Tu programa recibe precios, consulta el historial y envía órdenes a una o varias cuentas.

Protobuf o JSON · TCP o WebSocket con TLS · OAuth 2.0

Estándar institucional

FIX API

El idioma de bancos y fondos desde los años noventa. Dos líneas: una para precios y otra para órdenes. Sin gráficos ni historial.

FIX 4.4 · sesiones QUOTE y TRADE · puertos 5211 y 5212 con TLS

Robots en la plataforma

cBots

Programas que viven dentro de cTrader, con backtest y optimizador. Corren en tu ordenador, en la nube gratuita de cTrader o en un servidor Linux.

C# o Python (desde cTrader 5.4) · cTrader Cloud · CLI en Docker

Agentes de IA

MCP

Un enchufe para que Claude Code u otro agente consulte tu cuenta, los precios y el historial, y opere si se lo permites.

Diseño

La arquitectura correcta

Una sola pieza envía órdenes, y solo después de pasar un control de riesgo escrito en código. El agente de IA mira, analiza y propone desde fuera.

  • Stop en el servidor desde el primer instante. La orden de mercado lleva su stop, así un corte de tu sistema no deja la posición sin protección.
  • La verdad es la del bróker. Al arrancar y tras cada reconexión, el ejecutor pide las posiciones y órdenes abiertas y las compara con lo que cree tener.
  • Permisos mínimos. La aplicación que solo lee usa el permiso «accounts»; solo el ejecutor tiene «trading».
  • Un botón de parada que no dependa de la estrategia. Cancela las órdenes pendientes, cierra posiciones y bloquea nuevas entradas. El documento 6 detalla qué límites ponerle.

Implementación

Open API, paso a paso

  1. Registra la aplicaciónEn el portal de Open API, con tu cTID. Recibes un client ID y un secreto. Spotware revisa la solicitud y te responde por correo.
  2. Autoriza tus cuentas con OAuth 2.0El titular inicia sesión en la página de cTrader y concede «accounts» (solo lectura) o «trading». El token de acceso dura unos 30 días; el de renovación vale hasta que lo usas.
  3. Conecta con TLSlive.ctraderapi.com o demo.ctraderapi.com, puerto 5035 para Protobuf o 5036 para JSON, por TCP o WebSocket. Demo y real están separados: abre una conexión para cada entorno; cada una admite cuentas ilimitadas.
  4. Autentica en ordenProtoOAApplicationAuthReq, después ProtoOAGetAccountListByAccessTokenReq y ProtoOAAccountAuthReq para cada cuenta. Cualquier otro mensaje antes de eso devuelve un error.
  5. Mantén la línea vivaUn ProtoHeartbeatEvent cada 10 segundos.
  6. Carga la ficha de cada símboloProtoOASymbolsListReq y ProtoOASymbolByIdReq: identificador, dígitos, tamaño de lote, volumen mínimo y paso. Cambian de un bróker a otro.
  7. Recibe precios e historialProtoOASubscribeSpotsReq para los precios en directo y ProtoOAGetTrendbarsReq para las barras, con un máximo de 14.000 por petición y 5 peticiones por segundo.
  8. Envía órdenes con tu propio identificadorProtoOANewOrderReq con clientOrderId y stop relativo. El resultado llega como ProtoOAExecutionEvent o ProtoOAOrderErrorEvent.
  9. Reconcilia y renuevaProtoOAReconcileReq al arrancar y tras cada reconexión; ProtoOARefreshTokenReq antes de que caduque el token.

Las unidades que rompen sistemas

La Open API no habla en lotes ni en pips. El volumen va en centésimas de unidad, los precios en cienmilésimas y el stop de una orden de mercado solo se admite como distancia relativa. Un error aquí multiplica tu posición por cien.

Un esqueleto en Python

Con la librería oficial, OpenApiPy (pip install ctrader-open-api==0.9.2). Conecta a demo, autentica, reconcilia, se suscribe a precios y deja lista una función de compra con stop en el servidor.

Python · OpenApiPy
import os
import uuid

from twisted.internet import reactor, task
from ctrader_open_api import Client, EndPoints, Protobuf, TcpProtocol
from ctrader_open_api.messages.OpenApiCommonMessages_pb2 import ProtoHeartbeatEvent
from ctrader_open_api.messages.OpenApiMessages_pb2 import (
    ProtoOAAccountAuthReq, ProtoOAApplicationAuthReq, ProtoOANewOrderReq,
    ProtoOAReconcileReq, ProtoOASubscribeSpotsReq)
from ctrader_open_api.messages.OpenApiModelMessages_pb2 import (
    ProtoOAOrderType, ProtoOATradeSide)

CUENTA = int(os.environ["CTRADER_CUENTA"])  # ctidTraderAccountId
EURUSD = 1  # symbolId: cámbialo por el que devuelva ProtoOASymbolsListReq

client = Client(EndPoints.PROTOBUF_DEMO_HOST, EndPoints.PROTOBUF_PORT, TcpProtocol)


def ok(respuesta):
    """Extrae el mensaje y convierte las respuestas de error en excepciones."""
    m = Protobuf.extract(respuesta)
    if type(m).__name__ == "ProtoOAErrorRes":
        raise RuntimeError(f"{m.errorCode}: {m.description}")
    return m


def pedir(req, siguiente):
    client.send(req).addCallback(ok).addCallbacks(siguiente, fallo)


def al_conectar(_):
    req = ProtoOAApplicationAuthReq()
    req.clientId = os.environ["CTRADER_CLIENT_ID"]
    req.clientSecret = os.environ["CTRADER_CLIENT_SECRET"]
    pedir(req, autorizar_cuenta)


def autorizar_cuenta(_):
    pedir(ProtoOAAccountAuthReq(ctidTraderAccountId=CUENTA,
                                accessToken=os.environ["CTRADER_ACCESS_TOKEN"]),
          reconciliar)


def reconciliar(_):
    # Antes de operar, la verdad del bróker: posiciones y órdenes abiertas
    pedir(ProtoOAReconcileReq(ctidTraderAccountId=CUENTA), suscribir)


def suscribir(estado):
    print("Posiciones abiertas:", len(estado.position))
    pedir(ProtoOASubscribeSpotsReq(ctidTraderAccountId=CUENTA, symbolId=[EURUSD]),
          lambda _: print("Suscrito a EURUSD"))


def comprar(lotes, stop_pips):
    """Llámala solo después de que el control de riesgo apruebe la orden."""
    req = ProtoOANewOrderReq(
        ctidTraderAccountId=CUENTA, symbolId=EURUSD,
        orderType=ProtoOAOrderType.Value("MARKET"),
        tradeSide=ProtoOATradeSide.Value("BUY"),
        volume=round(lotes * 100_000 * 100),                   # centésimas de unidad
        relativeStopLoss=round(stop_pips * 0.0001 * 100_000),  # cienmilésimas de precio
        clientOrderId=uuid.uuid4().hex,                        # evita duplicados al reintentar
        label="tendencia-v1")
    client.send(req).addErrback(fallo)  # la ejecución llega como evento


def al_recibir(_, mensaje):
    if mensaje.payloadType == ProtoHeartbeatEvent().payloadType:
        return
    print(Protobuf.extract(mensaje))  # precios, ejecuciones y errores de orden


def fallo(error):
    print("ERROR:", error)  # en producción: alerta y parar la estrategia


def al_desconectar(_, motivo):
    print("Desconectado:", motivo)  # al volver se autentica y reconcilia de nuevo


def latido():  # cTrader pide uno cada 10 s; no tiene respuesta
    client.send(ProtoHeartbeatEvent()).addErrback(lambda _: None)


client.setConnectedCallback(al_conectar)
client.setDisconnectedCallback(al_desconectar)
client.setMessageReceivedCallback(al_recibir)
task.LoopingCall(latido).start(10, now=False)
client.startService()
reactor.run()

Código educativo. Faltan piezas imprescindibles en real: el control de riesgo, la renovación del token, la cola que respeta los límites de peticiones y el registro. Las credenciales se leen del entorno; guárdalas en un gestor de secretos, nunca en el código.

Agentes de IA

MCP con Claude, bien configurado

Es la vía más fácil de montar y la más delicada, porque un modelo de lenguaje elige qué herramienta usar a partir de tu texto.

Servidor local, en tu ordenador

  1. Abre cTrader Windows o Mac con tu cTIDVe a Configuración y después a MCP Server. La aplicación tiene que estar abierta antes que el agente.
  2. Activa «Enable MCP server»Deja «Allow trading via MCP» desactivado mientras lo uses para analizar. Si algún día lo activas, activa también «Require confirmation for trading operations».
  3. Añádelo a Claude CodeCon el comando de abajo, o pegando en la configuración de tu cliente el bloque JSON que muestra cTrader.
Terminal
claude mcp add --transport http ctrader http://127.0.0.1:9876/mcp/
JSON · otros clientes
{
  "mcpServers": {
    "ctrader": { "type": "http", "url": "http://127.0.0.1:9876/mcp/" }
  }
}

Servidor remoto, a través de cTrader Web

En cTrader Web, Configuración y después Remote MCP. cTrader genera un token para cada cuenta y te da la configuración lista para copiar. Funciona mientras tu sesión de cTrader Web siga activa. Además de Claude Code, cTrader cita como clientes compatibles Codex, Cursor, Windsurf, Gemini CLI y GitHub Copilot.

Lo que no hay que hacer

Publicar el puerto 9876 fuera de tu equipo, guardar el token remoto en un repositorio o en un chat, y dejar que el mismo agente lea webs o noticias y pueda operar. Un texto malicioso puede colar instrucciones: es la inyección de instrucciones, el riesgo que más señalan los investigadores de seguridad en el protocolo MCP.

Buenos usos

  • Diario y resúmenes de la cuenta, con costes incluidos.
  • Revisar exposición por divisa y margen antes de las noticias.
  • Comparar lo que dice tu registro con lo que hay en la cuenta.
  • Ayuda para escribir y depurar cBots en C# o Python.

Malos usos

  • Operar por impulsos desde el chat.
  • Dejarle operar sin confirmación, o en una cuenta con mucho saldo.
  • Usarlo como motor de ejecución: tarda segundos y no responde siempre igual.
  • Mezclar en la misma sesión la lectura de fuentes externas y el permiso para operar.

Un encargo bien planteado

Tú, a Claude Code con el MCP de cTraderAnaliza mis operaciones cerradas de los últimos 90 días en esta cuenta. Agrúpalas por hora de entrada y por símbolo, y dime en qué franjas pierdo más después de comisiones y swaps. Solo lectura: no abras, cierres ni modifiques nada.
