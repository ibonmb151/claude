El núcleo, pieza a pieza

La especificación técnica de todo lo que corre dentro de una célula: unidades, eventos, el motor, los datos, las tres estrategias, el tamaño, el riesgo, las órdenes, el cliente de cTrader y el diario. Con el código de cada pieza, probado, listo para programar.

Septiembre de 2026 · 75 minutos de lectura

13MM · 13 · 2026

En corto

  • Todo gira alrededor de un bucle con un solo consumidor: cada entrada se anota en el diario, el núcleo la procesa sin leer el reloj ni tocar la red, y ninguna orden sale sin estar escrita en disco. Así el mismo código sirve para el backtest, la repetición, la sombra y el dinero real.
  • Precios, volúmenes y dinero son enteros con las escalas de la Open API: 1e-5 para precios, centésimas de unidad para volúmenes y 1e-8 para dinero. Los decimales solo existen dentro de los indicadores.
  • Toda posición tiene stop en el servidor del bróker en menos de dos segundos o se cierra, y cualquier duda se resuelve preguntando al bróker: su estado manda sobre el nuestro.
  • El código no es decorativo. Las piezas que funcionan solas se ejecutaron y se probaron al escribir este documento: unidades, velas, estrategias, tamaño, pérdida diaria, estados de riesgo, conciliación, diario y el cliente de cTrader, este contra un servidor falso con TLS. El motor, el gestor de órdenes y las comprobaciones muestran su lógica completa; se terminan con el plan del documento 14.

Alcance

Cómo leer esta especificación

El documento 12 contó la plataforma sin tecnicismos. Este baja al detalle de lo que corre dentro de una célula; el 14 cubre lo que la rodea: guardián, gemelo, laboratorio, Jev, varias sedes, despliegue, seguridad, pruebas de sistema y el plan de trabajo.

Cada requisito lleva un identificador para poder citarlo en una tarea, una prueba o una revisión de código, y una palabra que dice cuánto obliga:

  • DEBE o NO DEBE: obligatorio. Si el código no lo cumple, es un error y no se despliega.
  • DEBERÍA: lo esperado. Saltárselo exige una decisión escrita en docs/adr/.
  • El código usa identificadores en inglés, como el resto del ecosistema de Python; los comentarios, los mensajes y la documentación van en español.

Los ocho requisitos que no se discuten

IdNivelRequisito
NUC-01DEBEUn solo proceso escribe órdenes para cada cuenta, y solo mientras tiene el cerrojo con al menos 10 segundos de margen.
NUC-02DEBEToda entrada se anota en el diario antes de procesarse, y toda orden se escribe en disco con fsync antes de enviarse.
NUC-03DEBEEl núcleo es determinista: con las mismas entradas produce los mismos eventos derivados, byte a byte.

Unidades

La mitad de los errores caros de un sistema de trading son de unidades: un volumen cien veces mayor, un precio con un decimal de menos, dinero en la divisa equivocada. Por eso se fijan una vez y para todo el código.

Dominio

Tipos y unidades

Pocos tipos, inmutables y con las mismas unidades en todas partes. Las conversiones viven en un solo fichero y en ningún otro sitio se multiplica por cien mil.

"""Unidades exactas. Fuera de los adaptadores no hay float para precios, volúmenes ni dinero."""
from __future__ import annotations

from fractions import Fraction
from typing import NewType

Price = NewType("Price", int)    # 1e-5 de unidad de precio, igual que la Open API
Volume = NewType("Volume", int)  # centésimas de unidad: 1 lote FX estándar = 10_000_000
Money = NewType("Money", int)    # 1e-8 de la divisa de la cuenta
TsNs = NewType("TsNs", int)      # nanosegundos UTC desde 1970

PRICE_SCALE = 100_000
MONEY_SCALE = 100_000_000
NS = 1_000_000_000


def price_from_api(x: float) -> Price:
    """Precio absoluto (double) de la API, p. ej. position.stopLoss, a entero exacto."""
    return Price(round(x * PRICE_SCALE))


def price_to_api(p: Price, digits: int) -> float:
    """Entero a double redondeado a los dígitos del símbolo (stopLoss, limitPrice...)."""
    return round(p / PRICE_SCALE, digits)


def money_from_api(v: int, money_digits: int) -> Money:
    """Importe con moneyDigits de la API a nuestra escala fija de 1e-8."""
    if not 0 <= money_digits <= 8:
        raise ValueError(f"moneyDigits fuera de rango: {money_digits}")
    return Money(v * 10 ** (8 - money_digits))


def tick_size(digits: int) -> int:
    """Tick del símbolo en 1e-5: EURUSD (5 dígitos) 1, USDJPY (3) 100, US500 (2) 1000."""
    return 10 ** max(0, 5 - digits)


def relative_distance(distance: int, digits: int) -> int:
    """Distancia para relativeStopLoss: múltiplo del tick, redondeada hacia fuera, nunca más cerca."""
    t = tick_size(digits)
    return -(-distance // t) * t


def pnl_quote(entry: Price, exit_: Price, volume: Volume, sign: int) -> Money:
    """Resultado exacto en la divisa de cotización.

    Δprecio real = Δp / 1e5 y unidades = volumen / 100; en 1e-8 queda Δp · volumen · 10.
    """
    return Money(sign * (exit_ - entry) * volume * 10)


def convert(m: Money, rate: Price, *, divide: bool = False) -> Money:
    """Cambia de divisa con un tipo en 1e-5, con redondeo exacto al entero más cercano.

    divide=True cuando el símbolo cotiza la divisa de destino como base (USD -> EUR con EURUSD).
    """
    q = Fraction(m * PRICE_SCALE, rate) if divide else Fraction(m * rate, PRICE_SCALE)
    return Money(round(q))

Con dinero en coma flotante, 0,1 + 0,2 da 0,30000000000000004: tras miles de operaciones, el saldo del diario deja de cuadrar con el del bróker por céntimos y la conciliación empieza a dar falsas alarmas. Con enteros, cuadra al céntimo o hay un error de verdad.

Cómo evolucionan

  • Un campo nuevo siempre es opcional y con valor por defecto: los diarios viejos se siguen leyendo.
  • Un campo no se renombra ni cambia de unidad. Si hace falta, se crea un evento nuevo con otra etiqueta y el viejo se sigue decodificando.
  • Cada registro del diario lleva la versión del software que lo escribió. La repetición usa esa versión o avisa de que el resultado puede diferir.
  • msgspec codifica en msgpack con orden determinista: las claves de los diccionarios salen ordenadas y el mismo evento produce siempre los mismos bytes, que es lo que permite comparar hashes.

Motor

El motor: un bucle, un orden

El núcleo es una función: recibe el estado y un evento, y devuelve el estado nuevo, los eventos derivados y los efectos. Todo lo que habla con el mundo está fuera, en adaptadores que se cambian según el modo.

"""El núcleo: todo el estado de la célula y su única transición, step()."""
from __future__ import annotations

from mym.core.events import (ClockTick, Command, ConnEv, Ev, ExecIn, LeaseEv, OrderErrorIn,
                             ReconcileIn, Sent, Spot)


class Core:
    def step(self, ev: Ev) -> StepOut:
        out = StepOut(ts=ev.ts)
        self.clock.advance(ev.ts)                        # el tiempo solo avanza con los eventos
        match ev:
            case Spot():
                self.market.on_spot(ev, out)             # velas M1, frescura, desfase de reloj
                self.book.mark(ev, out)                  # equity y pérdida del día al momento
            case ClockTick():
                self.market.on_clock(ev, out)            # cierra velas sin ticks, marca datos viejos
                self.book.on_clock(ev, out)              # cambio de día de la firma, marcas por minuto
                self.oms.on_clock(ev, out)               # tiempos de espera
                out.timer = True
            case Sent():
                self.oms.on_sent(ev, out)
            case ExecIn() | OrderErrorIn():
                self.oms.on_broker(ev, out)              # estados de orden y protección
                self.book.on_broker(ev, out)             # posiciones, saldo, comisiones
            case ReconcileIn():
                self.oms.reconcile(ev, self.book, out)
            case Command():
                self.risk.on_command(ev, out)
            case LeaseEv():
                self.risk.on_lease(ev, out)
                self.oms.on_lease(ev.epoch)              # turno nuevo: prefijo nuevo de clientOrderId
            case ConnEv():
                self.risk.on_conn(ev, out)
        # Cascada fija, siempre en este orden y con los mismos datos:
        for bar in out.bars_closed:
            self.strategies.on_bar(bar, self.market, out)             # velas -> objetivos
        if out.timer:
            self.strategies.on_timer(ev.ts, self.market, out)
        for fill in out.position_changes:
            self.strategies.on_position(fill, out)                    # la estrategia sabe si entró
        self.portfolio.plan(out.targets, self.book, self.market, out) # objetivos -> intenciones
        self.risk.review(out.intents, self.book, self.market, out)    # intenciones -> aprobadas
        self.oms.submit(out.approved, out)                            # aprobadas -> OrderNew + envío
        self.risk.update_state(self.book, out)                        # máquina de estados
        return out

  1. Cargar la configuraciónValidar, comprobar la firma del operador y calcular su hash, que se anota como primer evento.

"""Descarga de velas M1 del servidor del bróker: ventanas de un día, sin pasarse de los límites."""
from __future__ import annotations

from mym.ctrader.client import CTraderClient
from mym.ctrader.proto import OpenApiMessages_pb2 as om
from mym.ctrader.proto import OpenApiModelMessages_pb2 as mo
from mym.data.bars import decode_trendbar

DAY_MS = 86_400_000
Row = tuple[int, int, int, int, int, int]          # ts_open, o, h, l, c, ticks


async def fetch_window(c: CTraderClient, ctid: int, symbol_id: int, frm: int, to: int) -> list[Row]:
    """Una ventana [frm, to] en ms. Si la respuesta viene recortada (hasMore), se parte en dos:
    funciona igual devuelva el servidor las velas más nuevas o las más viejas."""
    res = await c.request(om.ProtoOAGetTrendbarsReq(
        ctidTraderAccountId=ctid, period=mo.M1, symbolId=symbol_id,
        fromTimestamp=frm, toTimestamp=to), timeout=30)
    rows = [(*decode_trendbar(tb), tb.volume) for tb in res.trendbar]
    if not res.hasMore or to - frm < 120_000:
        return rows
    mid = (frm + to) // 2
    return (await fetch_window(c, ctid, symbol_id, frm, mid)
            + await fetch_window(c, ctid, symbol_id, mid + 1, to))


async def fetch_m1(c: CTraderClient, ctid: int, symbol_id: int, start_ms: int,
                   end_ms: int) -> list[Row]:
    """Día a día, deduplicado por hora de apertura y ordenado. El cliente ya respeta
    las 5 peticiones/s históricas y el retryAfter de BLOCKED_PAYLOAD_TYPE."""
    seen: dict[int, Row] = {}
    for frm in range(start_ms - start_ms % DAY_MS, end_ms, DAY_MS):
        for r in await fetch_window(c, ctid, symbol_id, frm, min(frm + DAY_MS - 1, end_ms)):
            seen[r[0]] = r
    rows = [seen[k] for k in sorted(seen)]
    bad = [r for r in rows if not (r[3] <= min(r[1], r[4]) <= max(r[1], r[4]) <= r[2])]
    if bad:
        raise ValueError(f"{len(bad)} velas incoherentes (l <= o, c <= h)")
    return rows

La descarga va día a día: cada mes se escribe entero en un fichero temporal, se calcula su hash y se renombra, así que nunca queda un Parquet a medias. Los dos últimos días se vuelven a pedir en cada ejecución, porque las velas más recientes pueden llegar incompletas.

from __future__ import annotations

from zoneinfo import ZoneInfo

from mym.core.domain import Bar
from mym.core.units import NS, Price

NY = ZoneInfo("America/New_York")
MIN = 60 * NS


def trading_day(ts: int) -> date:
    """De 17:00 NY del día anterior a 17:00 NY, con los cambios de hora incluidos.
    La sesión del domingo por la tarde cuenta como lunes: no hay velas de domingo."""
    t = datetime.fromtimestamp(ts // NS, NY)
    d = t.date() + timedelta(days=1) if t.time() >= time(17, 0) else t.date()
    while d.weekday() >= 5:
        d += timedelta(days=1)
    return d


def decode_trendbar(tb: object) -> tuple[int, int, int, int, int]:
    """ProtoOATrendbar -> (ts_open, o, h, l, c). Precios en 1e-5, relativos al mínimo."""
    low = tb.low                                             # type: ignore[attr-defined]
    return (tb.utcTimestampInMinutes * MIN,                  # type: ignore[attr-defined]
            low + tb.deltaOpen, low + tb.deltaHigh, low,     # type: ignore[attr-defined]
            low + tb.deltaClose)                             # type: ignore[attr-defined]


@dataclass(slots=True)
class _Acc:
    key: str
    minute: int                                              # minutos Unix del servidor
    o: int
    h: int
    l: int  # noqa: E741
    c: int
    n: int = 0
    spread_sum: int = 0

    def add(self, bid: int, ask: int) -> None:
        self.h, self.l, self.c = max(self.h, bid), min(self.l, bid), bid
        self.n += 1
        self.spread_sum += ask - bid

    def close(self) -> Bar:
        return Bar(self.key, "M1", self.minute * MIN, Price(self.o), Price(self.h), Price(self.l),
                   Price(self.c), self.n, self.spread_sum // max(self.n, 1))


class M1Builder:
    """Agrega spots en velas de un minuto con el bid, como los trendbars de cTrader.
    Sin ticks no hay vela: igual que en el bróker (sus velas solo existen si hubo ticks)."""

    def __init__(self, key: str, grace_s: int = 3) -> None:
        self.key, self.grace_s = key, grace_s
        self.cur: _Acc | None = None
        self.late = 0                                        # ticks que llegaron tarde: métrica

    def on_spot(self, ts_broker_ms: int, bid: int, ask: int) -> Bar | None:
        minute = ts_broker_ms // 60_000
        if self.cur is not None and minute < self.cur.minute:
            self.late += 1                                   # tick de un minuto ya cerrado
            return None
        done = None
        if self.cur is not None and minute > self.cur.minute:
            done, self.cur = self.cur.close(), None
        if self.cur is None:
            self.cur = _Acc(self.key, minute, bid, bid, bid, bid)
        self.cur.add(bid, ask)
        return done

    def on_clock(self, ts: int) -> Bar | None:
        """Cierra la vela abierta si su minuto acabó hace más de grace_s segundos."""
        if self.cur is not None and ts // NS >= (self.cur.minute + 1) * 60 + self.grace_s:
            done, self.cur = self.cur.close(), None
            return done
        return None


class Resampler:
    """M1 -> vela mayor (M5 o D1). Emite en cuanto llega la M1 que cierra el periodo,
    o por reloj si esa M1 no existe (minuto sin ticks)."""

    def __init__(self, key: str, tf: str, grace_s: int = 3) -> None:
        self.key, self.tf, self.grace_s = key, tf, grace_s
        self.cur: tuple[int | date, list[Bar]] | None = None

    def bucket(self, ts_open: int) -> int | date:
        if self.tf == "M5":
            return ts_open // (5 * MIN)
        if self.tf == "D1":
            return trading_day(ts_open)
        raise ValueError(self.tf)

    def end_of(self, k: int | date) -> int:
        """Instante (TsNs) en que termina la vela k."""
        if isinstance(k, date):
            return int(datetime(k.year, k.month, k.day, 17, 0, tzinfo=NY).timestamp()) * NS
        return (k + 1) * 5 * MIN

    def on_m1(self, b: Bar) -> list[Bar]:
        out: list[Bar] = []
        k = self.bucket(b.ts_open)
        if self.cur is not None and k != self.cur[0]:
            out.append(self._merge(self.cur[1]))             # periodo anterior sin su última M1
            self.cur = None
        if self.cur is None:
            self.cur = (k, [])
        self.cur[1].append(b)
        if b.ts_open + MIN >= self.end_of(k):                # esta M1 cierra el periodo
            out.append(self._merge(self.cur[1]))
            self.cur = None
        return out

    def on_clock(self, ts: int) -> list[Bar]:
        if self.cur is not None and ts >= self.end_of(self.cur[0]) + self.grace_s * NS:
            done, self.cur = self._merge(self.cur[1]), None
            return [done]
        return []

    def _merge(self, bs: list[Bar]) -> Bar:
        n = sum(b.ticks for b in bs)
        spread = sum(b.spread_avg * b.ticks for b in bs) // max(n, 1)
        return Bar(self.key, self.tf, bs[0].ts_open, bs[0].o, Price(max(b.h for b in bs)),
                   Price(min(b.l for b in bs)), bs[-1].c, n, spread,
                   flags=0 if all(b.flags == 0 for b in bs) else 1)

Tendencias de semanas a meses en diez mercados poco relacionados entre sí.

MADRID = ZoneInfo("Europe/Madrid")
UNIVERSE = ("EURUSD", "GBPUSD", "USDJPY", "AUDUSD", "USDCAD", "USDCHF", "NZDUSD",
            "XAUUSD", "US500", "DE40")
EWMAC = ((16, 64, 3.75), (32, 128, 2.65))    # (rápida, lenta, escalar): |previsión| media ≈ 10
BRK_N, BRK_SMOOTH, BRK_SCALAR = 80, 20, 0.73
FDM = 1.10                                    # diversificación entre las tres reglas
CAP = 20.0
VOL_SPAN = 36                                 # desviación diaria del precio (EWMA)
ATR_N = 20
STOP_ATR = 4.0                                # stop de catástrofe, en el servidor
COOLDOWN_DAYS = 5                             # tras un stop, sin reabrir en el mismo sentido
WARMUP = 256
EXEC_AT = time(10, 0)                         # Madrid: Londres y Fráncfort ya abiertos


def alpha(span: int) -> float:
    return 2.0 / (span + 1.0)


@dataclass(slots=True)
class Leg:
    ema: dict[int, float] = field(default_factory=dict)
    var: float | None = None
    atr: float | None = None
    prev: float | None = None
    window: deque[float] = field(default_factory=lambda: deque(maxlen=BRK_N))
    brk: float | None = None
    n: int = 0

    def update(self, b: Bar) -> None:
        c = float(b.c)
        self.n += 1
        for f, s, _ in EWMAC:
            for span in (f, s):
                e = self.ema.get(span)
                self.ema[span] = c if e is None else e + alpha(span) * (c - e)
        if self.prev is not None:
            d = c - self.prev
            self.var = d * d if self.var is None else self.var + alpha(VOL_SPAN) * (d * d - self.var)
            tr = max(b.h - b.l, abs(b.h - self.prev), abs(b.l - self.prev))
            self.atr = tr if self.atr is None else self.atr + (tr - self.atr) / ATR_N   # Wilder
        self.prev = c
        self.window.append(c)
        if len(self.window) >= BRK_N // 2:
            hi, lo = max(self.window), min(self.window)
            raw = 0.0 if hi == lo else 40.0 * (c - (hi + lo) / 2) / (hi - lo)
            self.brk = raw if self.brk is None else self.brk + alpha(BRK_SMOOTH) * (raw - self.brk)

    def forecast(self) -> float | None:
        """Previsión combinada entre -20 y +20; None mientras calienta."""
        if self.n < WARMUP or not self.var or self.brk is None:
            return None
        sigma = math.sqrt(self.var)
        rules = [max(-CAP, min(CAP, (self.ema[f] - self.ema[s]) / sigma * k)) for f, s, k in EWMAC]
        rules.append(max(-CAP, min(CAP, self.brk * BRK_SCALAR)))
        return max(-CAP, min(CAP, FDM * sum(rules) / len(rules)))


@dataclass(slots=True)
class TendD1:
    id: str = "TEND-D1"
    legs: dict[str, Leg] = field(default_factory=dict)
    pending: dict[str, Target] = field(default_factory=dict)
    held: dict[str, int] = field(default_factory=dict)                   # sentido abierto
    cooldown: dict[str, tuple[int, int]] = field(default_factory=dict)   # key -> (hasta, sentido)
    last_exec: str = ""

    def warmup(self) -> dict[str, tuple[str, int]]:
        return {k: ("D1", WARMUP + 44) for k in UNIVERSE}

    def on_bar(self, bar: Bar, mkt: MarketView) -> list[Target]:
        if bar.tf != "D1" or bar.key not in UNIVERSE or bar.flags:
            return []                                      # vela marcada como sospechosa: fuera
        leg = self.legs.setdefault(bar.key, Leg())
        leg.update(bar)
        f = leg.forecast()
        if f is not None and leg.atr and leg.var:
            self.pending[bar.key] = Target(
                strategy=self.id, key=bar.key, size=round(f / CAP, 6),
                stop_distance=round(STOP_ATR * leg.atr), take_profit=None, time_stop_ns=None,
                price_vol=round(math.sqrt(leg.var)), reason=f"previsión {f:+.2f}")
        return []

    def on_timer(self, ts: int, mkt: MarketView) -> list[Target]:
        t = datetime.fromtimestamp(ts // NS, MADRID)
        today = t.date().isoformat()
        if t.weekday() >= 5 or t.time() < EXEC_AT or today == self.last_exec or not self.pending:
            return []
        self.last_exec = today                             # una vez al día, desde las 10:00
        out = []
        for k in sorted(self.pending):
            tg = self.pending[k]
            until, sign = self.cooldown.get(k, (0, 0))
            if ts < until and tg.size * sign > 0:          # mismo sentido que el stop reciente
                tg = Target(self.id, k, 0.0, None, None, None, tg.price_vol, "enfriamiento tras stop")
            out.append(tg)
        self.pending.clear()
        return out

    def on_position(self, ch: PositionChange) -> list[Target]:
        if ch.side != 0:
            self.held[ch.key] = ch.side
            return []
        sign = self.held.pop(ch.key, 0)
        if sign and ch.why in ("stop", "stop_out"):
            self.cooldown[ch.key] = (ch.ts + COOLDOWN_DAYS * 86_400 * NS, sign)
        return []

"""REV-M5: reversión a la media de noche en EURUSD y EURGBP, con velas de 5 minutos."""
from __future__ import annotations

import math
from dataclasses import dataclass, field
from datetime import UTC, date, datetime, time

from mym.core.domain import Bar, Target
from mym.core.units import NS, Price
from mym.strategies.base import MarketView, PositionChange

UNIVERSE = ("EURUSD", "EURGBP")
CCYS = {"EURUSD": ("EUR", "USD"), "EURGBP": ("EUR", "GBP")}
ENTRY_FROM, ENTRY_UNTIL, HARD_EXIT = time(0, 30), time(6, 0), time(6, 30)   # UTC
SPAN = 48                              # 4 horas de velas M5
K_ENTRY = 2.2                          # desviaciones para entrar
SL_MULT = 1.5                          # stop = 1,5 × distancia a la media al entrar
TIME_STOP = 60 * 60 * NS
MAX_TRADES, MAX_LOSSES = 2, 2          # por instrumento y noche
MAX_SPREAD = {"EURUSD": 8, "EURGBP": 12}      # 1e-5: 0,8 y 1,2 pips
COMMISSION = {"EURUSD": 6, "EURGBP": 5}       # comisión ida y vuelta en precio, 1e-5: unos 3 $ por lote y lado
COST_MULT = 4.0                        # la distancia a la media debe cubrir 4 veces el coste


def alpha(span: int) -> float:
    return 2.0 / (span + 1.0)


@dataclass(slots=True)
class Leg:
    mean: float | None = None
    var: float | None = None           # varianza EWMA de la desviación a la media
    n: int = 0
    night: date | None = None
    trades: int = 0
    losses: int = 0
    side: int = 0                      # lo que la estrategia cree tener: +1, -1 o 0
    opened_ns: int | None = None
    closing: bool = False


@dataclass(slots=True)
class RevM5:
    id: str = "REV-M5"
    legs: dict[str, Leg] = field(default_factory=dict)

    def warmup(self) -> dict[str, tuple[str, int]]:
        return {k: ("M5", 2 * SPAN) for k in UNIVERSE}

    def on_bar(self, bar: Bar, mkt: MarketView) -> list[Target]:
        if bar.tf != "M5" or bar.key not in UNIVERSE:
            return []
        leg = self.legs.setdefault(bar.key, Leg())
        c = float(bar.c)
        if leg.mean is None:
            leg.mean = c
        dev = c - leg.mean                                   # se mide antes de mover la media
        leg.var = dev * dev if leg.var is None else leg.var + alpha(SPAN) * (dev * dev - leg.var)
        leg.mean += alpha(SPAN) * dev
        leg.n += 1
        end_ns = bar.ts_open + 5 * 60 * NS
        t = datetime.fromtimestamp(end_ns // NS, UTC)
        if leg.night != t.date():
            leg.night, leg.trades, leg.losses = t.date(), 0, 0
        if leg.side != 0:                                    # posición abierta: gestionar
            late = t.time() >= HARD_EXIT
            timeout = leg.opened_ns is not None and end_ns - leg.opened_ns >= TIME_STOP
            if late or timeout or bar.flags:
                return self._flat(bar.key, "salida por tiempo")
            return [Target(self.id, bar.key, float(leg.side), None, Price(round(leg.mean)),
                           None, None, "el objetivo sigue a la media")]
        if (leg.n < 2 * SPAN or bar.flags or not leg.var
                or not ENTRY_FROM <= t.time() < ENTRY_UNTIL
                or leg.trades >= MAX_TRADES or leg.losses >= MAX_LOSSES
                or bar.spread_avg > MAX_SPREAD[bar.key]):
            return []
        z = dev / math.sqrt(leg.var)
        dist = abs(c - leg.mean)
        if abs(z) < K_ENTRY or dist < COST_MULT * (bar.spread_avg + COMMISSION[bar.key]):
            return []
        cal = mkt.calendar()
        if any(cal.high_impact(ccy, end_ns, end_ns + TIME_STOP) for ccy in CCYS[bar.key]):
            return []                                        # noticia fuerte en la hora siguiente
        side = -1 if z > 0 else 1                            # contra el estiramiento
        return [Target(self.id, bar.key, float(side), round(SL_MULT * dist),
                       Price(round(leg.mean)), end_ns + TIME_STOP, None,
                       f"z {z:+.2f}, a {dist:.0f} de la media")]

    def on_timer(self, ts: int, mkt: MarketView) -> list[Target]:
        if datetime.fromtimestamp(ts // NS, UTC).time() < HARD_EXIT:
            return []
        out: list[Target] = []
        for k in sorted(self.legs):
            out += self._flat(k, "fin de la ventana")
        return out

    def on_position(self, ch: PositionChange) -> list[Target]:
        leg = self.legs.get(ch.key)
        if leg is None:
            return []
        if ch.side != 0 and leg.side == 0:                   # entrada confirmada por el bróker
            leg.side, leg.opened_ns, leg.closing = ch.side, ch.ts, False
            leg.trades += 1
        elif ch.side == 0 and leg.side != 0:                 # cerrada: stop, objetivo o salida
            leg.side, leg.opened_ns, leg.closing = 0, None, False
            if ch.pnl is not None and ch.pnl < 0:
                leg.losses += 1
        return []

    def _flat(self, key: str, why: str) -> list[Target]:
        leg = self.legs[key]
        if leg.side == 0 or leg.closing:                     # nada abierto o ya se pidió cerrar
            return []
        leg.closing = True
        return [Target(self.id, key, 0.0, None, None, None, None, why)]

La relación documentada entre la primera media hora de la sesión y la última: si el día empezó subiendo, la última media hora tiende a subir (Gao, Han, Li y Zhou, 2018).

US500, el CFD del S&P 500.

Rendimiento desde el cierre de las 16:00 del día anterior hasta las 10:00 de hoy, hora de Nueva York. Sin señal si no llega al 0,05 %.

from datetime import date, datetime, time
from zoneinfo import ZoneInfo

from mym.core.domain import Bar, Target
from mym.core.units import NS

ET = ZoneInfo("America/New_York")
KEY = "US500"
T_FIRST, T_ENTRY, T_CLOSE = time(10, 0), time(15, 30), time(16, 0)   # cierres de vela M1
T_EXIT = time(15, 58, 30)             # salir antes de la subasta de cierre
DEAD_ZONE = 0.0005                    # |r| < 0,05 %: sin señal
STOP_MULT, MIN_STOP = 3.0, 800        # 3 × mediana de |15:30→16:00| en 60 días; mínimo 8 puntos
LOOKBACK = 60


@dataclass(slots=True)
class MomUS500:
    id: str = "MOM-US500"
    prev_close: int | None = None     # precio de las 16:00 ET del día anterior
    p10: int | None = None            # precio de las 10:00 ET de hoy
    p1530: int | None = None
    day: date | None = None
    moves: deque[int] = field(default_factory=lambda: deque(maxlen=LOOKBACK))
    side: int = 0
    exit_sent: bool = False

    def warmup(self) -> dict[str, tuple[str, int]]:
        return {KEY: ("M1", 0)}       # los 60 movimientos se reconstruyen desde el histórico

    def on_bar(self, bar: Bar, mkt: MarketView) -> list[Target]:
        if bar.tf != "M1" or bar.key != KEY or bar.flags:
            return []
        end = datetime.fromtimestamp(bar.ts_open // NS + 60, ET)   # hora de cierre de la vela
        if end.date() != self.day:
            self.day, self.p10, self.p1530 = end.date(), None, None
        hm = end.time()
        if hm == T_FIRST:
            self.p10 = bar.c                                       # si falta esta vela, hoy no
        elif hm == T_ENTRY:
            self.p1530 = bar.c
            return self._entry(end.date(), mkt)
        elif hm == T_CLOSE:
            if self.p1530 is not None:
                self.moves.append(abs(bar.c - self.p1530))
            self.prev_close = bar.c
        return []

    def _entry(self, d: date, mkt: MarketView) -> list[Target]:
        cal = mkt.calendar()
        if (self.side != 0 or self.prev_close is None or self.p10 is None
                or len(self.moves) < LOOKBACK or cal.is_half_day(d)):
            return []                  # los días de noticias no se excluyen: ahí el efecto es mayor
        r = (self.p10 - self.prev_close) / self.prev_close
        if abs(r) < DEAD_ZONE:
            return []
        stop = max(MIN_STOP, round(STOP_MULT * statistics.median(self.moves)))
        exit_ns = int(datetime.combine(d, T_EXIT, ET).timestamp()) * NS
        self.exit_sent = False
        return [Target(self.id, KEY, 1.0 if r > 0 else -1.0, stop, None, exit_ns, None,
                       f"primera media hora {r:+.3%}")]

    def on_timer(self, ts: int, mkt: MarketView) -> list[Target]:
        t = datetime.fromtimestamp(ts // NS, ET)
        if self.side == 0 or self.exit_sent or t.time() < T_EXIT:
            return []
        self.exit_sent = True
        return [Target(self.id, KEY, 0.0, None, None, None, None, "salida 15:58:30")]

    def on_position(self, ch: PositionChange) -> list[Target]:
        if ch.key == KEY:
            self.side = ch.side
        return []

REV-M5 y MOM-US500 nunca tienen posiciones a la vez: una opera de madrugada y la otra al final de la tarde europea. Las de TEND-D1, en cambio, están abiertas casi siempre. Por eso el riesgo abierto máximo es el de la tendencia más el de una sola de las otras dos, y la cartera lo aprovecha.

Cartera

Del objetivo al volumen

La cartera traduce cada objetivo en una intención con volumen. Es la única pieza que mira el dinero: el saldo, el peso de cada estrategia, la divisa de cotización y el paso de volumen del símbolo.

Una posición por estrategia

Las cuentas de FTMO en cTrader son de cobertura (HEDGED): admiten varias posiciones en el mismo instrumento. Cada estrategia tiene las suyas, con su etiqueta, y nunca se compensan entre sí. Si TEND-D1 está larga en EURUSD y REV-M5 entra corta de madrugada, hay dos posiciones. Cuesta una horquilla de más de vez en cuando, pero a cambio cada resultado se atribuye sin ambigüedad a su estrategia, cada posición tiene su propio stop y apagar una estrategia no toca a las demás, que es lo que pide el documento 11 para aislar variables.

Las órdenes de mercado no admiten stop absoluto en la Open API: se envía la distancia en relativeStopLoss, en 1e-5 y redondeada al tick del símbolo, y el servidor coloca el stop a esa distancia del precio de ejecución.

import math

from mym.core.domain import InstrumentSpec
from mym.core.units import MONEY_SCALE, PRICE_SCALE, Money, Volume


def to_volume(units: float, spec: InstrumentSpec) -> Volume | None:
    """Unidades -> volumen del protocolo (centésimas de unidad), siempre hacia abajo."""
    v = math.floor(units * 100) // spec.step_volume * spec.step_volume
    if v < spec.min_volume:
        return None                         # redondear hacia arriba subiría el riesgo: no se opera
    return Volume(min(v, spec.max_volume))


def units_for_risk(risk: Money, stop_distance: int, q2a: float) -> float:
    """Unidades con las que, si salta el stop, se pierde `risk` en la divisa de la cuenta.
    q2a: tipo de la divisa de cotización a la de la cuenta (1.0 si coinciden)."""
    loss_per_unit = stop_distance / PRICE_SCALE * q2a
    return (risk / MONEY_SCALE) / loss_per_unit


def units_vol_target(size: float, equity: Money, price_vol: int, q2a: float, *,
                     vol_annual: float, inst_weight: float, idm: float, w: float) -> float:
    """Carver: (previsión / 10) · (capital · σ objetivo / 16) · peso · IDM / σ diaria por unidad.
    size = previsión / 20, así que previsión / 10 = 2 · size."""
    cash_vol_day = equity / MONEY_SCALE * vol_annual / 16.0
    unit_vol_day = price_vol / PRICE_SCALE * q2a
    return 2.0 * size * cash_vol_day * inst_weight * idm * w / unit_vol_day


def buffered(current: int, target: int, avg_abs: int, buffer: float = 0.10) -> int | None:
    """Zona muerta: si el objetivo se aleja más de un 10 % de la posición media, se opera
    solo hasta el borde de la zona. Devuelve None si no hay que tocar nada."""
    b = round(buffer * max(avg_abs, 1))
    if current < target - b:
        return target - b
    if current > target + b:
        return target + b
    return None


def quote_to_account(quote: str, account: str, chain: list[tuple[str, str, str]],
                     mids: dict[str, int]) -> float:
    """Tipo de la divisa de cotización a la de la cuenta. chain sale de
    ProtoOASymbolsForConversionReq(firstAssetId=cotización, lastAssetId=cuenta):
    [(símbolo, base, cotizada), ...]; mids en 1e-5."""
    rate, cur = 1.0, quote
    for sym, base, q in chain:
        mid = mids[sym] / PRICE_SCALE
        if base == cur:
            rate, cur = rate * mid, q
        elif q == cur:
            rate, cur = rate / mid, base
        else:
            raise ValueError(f"cadena rota en {sym}")
    if cur != account:
        raise ValueError(f"la cadena acaba en {cur}, no en {account}")
    return rate


def next_weight(cur: float, proposed: float, max_up_per_day: float = 0.25) -> float:
    """Peso de Jev para una estrategia: nunca pasa del nominal (1,0).
    Bajar es inmediato; subir, como mucho 0,25 al día."""
    p = min(1.0, max(0.0, proposed))
    return p if p <= cur else min(p, cur + max_up_per_day)


def scale_to_budget(risks: dict[str, int], budget: int) -> float:
    """Factor común para que la suma de riesgos a stop no pase del presupuesto (TEND-D1)."""
    total = sum(risks.values())
    return 1.0 if total <= budget else budget / total

Pesos de Jev y el mando de riesgo

Cada estrategia tiene un peso que multiplica su riesgo: 1 encendida, 0,5 en base y 0 apagada, los tres estados del documento 9. Ningún peso pasa de 1. Hasta su fase 3, Jev solo puede bajarlo; después, subir se hace como mucho 0,25 al día, y bajar, al momento. Por encima de todo hay un solo mando, risk_scale, entre 0,5 y 1,25, que multiplica el riesgo de las tres a la vez.

Con los valores de partida, la volatilidad diaria esperada de la cuenta queda entre el 0,5 y el 0,7 %: la tendencia aporta poco, porque su presupuesto de riesgo a stop la limita, y las otras dos, más. Es algo menos de lo que pide el documento 10, del 0,75 al 1 %. El laboratorio mide la volatilidad real en el backtest y en la incubación, y ajusta risk_scale sin tocar el código ni los límites de riesgo, que siguen mandando por encima.

        checks = OPENING if it.kind == "open" else CLOSING

        d = Decision(it, ok=not reasons, volume=vol, reasons=reasons)
        if d.ok:
            b.reserve(d)                                    # cuenta para las siguientes del paso
        out.append(d)
    return out

@dataclass(frozen=True, slots=True)
class FirmRules:
    tz: ZoneInfo                      # Europe/Prague para FTMO: el día cambia a medianoche CE(S)T
    daily_loss: float                 # 0.05 (dos fases) o 0.03 (una fase), sobre el saldo inicial
    max_loss: float                   # 0.10
    trailing_eod: bool                # una fase: el suelo sube con el mejor saldo al cierre


@dataclass(slots=True)
class FirmDay:
    initial: Money
    rules: FirmRules
    day: date | None = None
    ref: Money = Money(0)             # referencia del día: la lectura más exigente
    best_eod: Money = Money(0)        # mejor saldo al cierre de día (suelo móvil)

    def roll(self, ts: int, balance: Money, equity: Money) -> bool:
        """Llamar en cada evento con reloj. Devuelve True si empezó un día de la firma."""
        d = datetime.fromtimestamp(ts // NS, self.rules.tz).date()
        if d == self.day:
            return False
        if self.day is not None:
            self.best_eod = Money(max(self.best_eod, balance))
        self.day, self.ref = d, Money(max(balance, equity))
        return True

    def daily_floor(self) -> Money:
        """Equity mínima de hoy según la firma."""
        return Money(self.ref - round(self.initial * self.rules.daily_loss))

    def total_floor(self) -> Money:
        """Equity mínima absoluta. Fija (dos fases) o móvil con el mejor cierre (una fase)."""
        base = max(self.initial, self.best_eod) if self.rules.trailing_eod else self.initial
        return Money(base - round(self.initial * self.rules.max_loss))

    def daily_pnl(self, equity: Money) -> Money:
        return Money(equity - self.ref)

Los cuatro estados

Hay dos fuentes de estado. Las pérdidas son pegajosas: suben de gravedad al momento, pero durante el día nunca bajan solas. Las condiciones de operación son transitorias: si se pierde la conexión, el estado es SOLO_CERRAR mientras dure, y al volver y conciliar se recupera el que había. El estado efectivo es el más grave de los dos. En PARADA, la célula cierra todas sus posiciones a mercado y se queda fuera hasta que alguien lo revise y reanude en dos pasos.

    reduce_dd: float = 0.05           # caída desde el máximo

    floor_stop: float = 0.02          # a 2 % del suelo total: parada

    daily_pnl: float                  # fracción del saldo inicial (negativo = pérdida)
    to_floor: float                   # (equity - suelo total) / inicial
    drawdown: float                   # desde el máximo de equity
    lease_ok: bool                    # tengo el cerrojo con margen
    broker_ok: bool                   # conectado, autenticado y conciliado
    data_ok: bool                     # precios frescos y reloj en hora
    paused: bool                      # orden de pausa del plano de control
    fatal: str = ""                   # diario roto, posición ajena, stop-out...


def pnl_level(m: Metrics, lim: Limits) -> S:
    if m.fatal or m.daily_pnl <= -lim.stop_daily or m.to_floor <= lim.floor_stop:
        return S.PARADA
    if m.daily_pnl <= -lim.close_only_daily or m.to_floor <= lim.floor_close_only:
        return S.SOLO_CERRAR
    if m.daily_pnl <= -lim.reduce_daily or m.drawdown >= lim.reduce_dd:
        return S.REDUCIR
    return S.NORMAL


def ops_level(m: Metrics) -> S:
    if not (m.lease_ok and m.broker_ok) or m.paused:
        return S.SOLO_CERRAR
    if not m.data_ok:
        return S.REDUCIR
    return S.NORMAL

    lim: Limits
    sticky: S = S.NORMAL              # lo que viene de pérdidas: no baja solo durante el día

        if manual_resume or (day_rolled and self.sticky is not S.PARADA):

El gestor de órdenes

Cada orden es una pequeña máquina de estados. Nada se envía dos veces, nada se da por hecho sin respuesta del bróker, y toda posición acaba con stop en el servidor o cerrada.

La garantía del stop

  1. Al abrirLa orden de mercado lleva relativeStopLoss: el servidor pone el stop a esa distancia del precio de ejecución.
  2. Al ejecutarseSe compara position.stopLoss del evento con el esperado. Si falta o se aleja más de dos ticks, se envía ProtoOAAmendPositionSLTPReq con el stop absoluto.
  3. Si no se puede ponerPor ejemplo, porque el precio ya pasó el stop: se cierra la posición a mercado. Plazo total, 2 segundos.
  4. SiempreLa conciliación, cada 60 segundos, y el guardián, cada 5, buscan posiciones sin stop. Un stop nunca se aleja salvo por una orden firmada con su motivo.

    closing: dict[int, str] = field(default_factory=dict)      # positionId -> cid del cierre

    def new_cid(self) -> str:
        self.seq += 1
        return f"{self.cell}-e{self.epoch:04d}-{self.seq:09d}"   # 19 caracteres; el límite es 50

    def submit(self, approved: list[Decision], out: StepOut) -> None:
        for d in approved:
            it = d.intent
            o = Order(self.new_cid(), it.seq, it.kind, it.key, it.side, d.volume,
                      it.stop_distance, it.tp_distance, it.position_id, since=out.ts)
            self.orders[o.cid] = o
            if it.kind in ("close", "reduce") and it.position_id is not None:
                self.closing[it.position_id] = o.cid
            out.derive(OrderNew(ts=out.ts, cid=o.cid, intent_seq=it.seq, epoch=self.epoch))
            out.effect(send_effect(o, label=it.strategy, comment=f"c={self.cell};e={self.epoch};i={it.seq}"))

    def on_sent(self, ev: Sent, out: StepOut) -> None:
        self._move(self.orders[ev.cid], St.SENT, "escrita en el socket", out)

    def on_broker(self, ev: ExecIn | OrderErrorIn, out: StepOut) -> None:
        if isinstance(ev, ExecIn) and ev.exec_type in CASH:
            return                                             # swaps, depósitos: los lleva el libro
        o = self._find(ev)
        if o is None:
            if isinstance(ev, ExecIn) and ev.server_event:
                return                                         # stop, TP o stop-out del servidor:
                                                               # el libro cierra la posición
            out.derive(ReconDiff(ts=ev.ts, cls="evento_sin_orden", severity="media",
                                 detail=repr(ev)[:300], action="conciliar"))
            out.effect(RequestReconcile())
            return
        if isinstance(ev, OrderErrorIn):
            self._move(o, St.REJECTED, ev.code, out)
            out.effect(on_reject(o, ev.code))                  # tabla de errores -> acción
            return
        match ev.exec_type:
            case X.ACCEPTED:
                o.order_id = ev.order_id
                self._move(o, St.ACCEPTED, "aceptada", out)
            case X.PARTIAL_FILL | X.FILLED:
                o.filled += ev.filled or 0
                o.avg_price = ev.price or o.avg_price
                done = ev.exec_type == X.FILLED
                self._move(o, St.FILLED if done else St.PARTIAL, "ejecutada", out)
                if o.kind == "open" and done:
                    self._ensure_protected(o, ev, out)
            case X.REJECTED:
                self._move(o, St.REJECTED, ev.error or "rechazada", out)
                out.effect(on_reject(o, ev.error or ""))
            case X.CANCELLED | X.EXPIRED:
                self._move(o, St.CANCELLED if ev.exec_type == X.CANCELLED else St.EXPIRED, "fin", out)
            case X.REPLACED:                                   # stop o TP cambiados: en una orden
                self._move(o, St.FILLED, "protección aplicada", out)   # "amend", FILLED = aplicada
            case X.CANCEL_REJECTED:
                out.effect(RequestReconcile())

    def _ensure_protected(self, o: Order, ev: ExecIn, out: StepOut) -> None:
        """Toda apertura acaba con stop en el servidor, o cerrada. Sin excepciones."""
        assert o.stop_distance is not None and ev.price is not None
        want = ev.price - o.sign * o.stop_distance              # entrada ∓ distancia
        if ev.pos_sl is not None and abs(ev.pos_sl - want) <= 2 * tick_size(self.specs[o.key].digits):
            return
        out.derive(ReconDiff(ts=ev.ts, cls="sin_stop", severity="alta",
                             detail=f"posición {ev.position_id} sin stop", action="poner stop"))
        out.effect(AmendSLTP(position_id=ev.position_id, sl=want, then_close_on_error=True))

    def on_clock(self, ts: int, out: StepOut) -> None:
        for o in list(self.orders.values()):
            age = ts - o.since
            if o.state is St.SENT and age > ACK_TIMEOUT:
                self._move(o, St.UNKNOWN, "sin respuesta en 5 s", out)
                out.effect(RequestReconcile())
            elif o.state is St.ACCEPTED and o.kind != "amend" and age > FILL_TIMEOUT:
                self._move(o, St.UNKNOWN, "aceptada sin ejecución en 10 s", out)
                out.effect(RequestReconcile())
            elif o.state is St.UNKNOWN and age > UNKNOWN_TIMEOUT:
                self._move(o, St.LOST, "la conciliación no la encuentra", out)

    def on_lease(self, epoch: int) -> None:
        self.epoch, self.seq = epoch, 0                        # turno nuevo: identificadores nuevos

    def _find(self, ev: ExecIn | OrderErrorIn) -> Order | None:
        cid = getattr(ev, "cid", None)
        if cid and cid in self.orders:
            return self.orders[cid]
        if ev.position_id in self.closing:                     # los cierres no traen clientOrderId
            return self.orders[self.closing[ev.position_id]]
        if ev.order_id is not None:
            return next((o for o in self.orders.values() if o.order_id == ev.order_id), None)
        return None

    def _move(self, o: Order, new: St, why: str, out: StepOut) -> None:
        if o.state in TERMINAL and new is not o.state:
            out.derive(ReconDiff(ts=out.ts, cls="transición_imposible", severity="alta",
                                 detail=f"{o.cid}: {o.state} -> {new}", action="conciliar"))
            return                                             # un estado final no se reabre
        out.derive(OmsMove(ts=out.ts, cid=o.cid, old=o.state, new=new, why=why))
        o.state, o.since = new, out.ts

    ref: int                          # positionId u orderId
    why: str
    severity: str                     # baja | media | alta

def reconcile(local: dict[int, LocalPos], snap: ReconcileIn, *, cell: str, epoch: int,
              local_balance: int, foreign: str = "alert") -> list[Action]:
    acts: list[Action] = []
    seen: set[int] = set()
    for p in snap.positions:
        seen.add(p.position_id)
        tag = TAG.search(p.comment or "")
        mine = tag is not None and tag["cell"] == cell
        lp = local.get(p.position_id)
        if lp is None and mine:
            same_turn = int(tag["epoch"]) == epoch if tag else False
            acts.append(Action("adopt", p.position_id,
                               "ejecución que no llegó al diario" if same_turn
                               else "abierta en un turno anterior (relevo)", "media"))
        elif lp is None:
            acts.append(Action("alert", p.position_id, "posición ajena en la cuenta", "alta",
                               close_only=foreign != "adopt"))
            continue                                      # lo ajeno no se toca solo
        elif (p.volume, p.sl) != (lp.volume, lp.sl):
            acts.append(Action("adopt", p.position_id, "difiere del diario: manda el bróker", "media"))
        if p.sl is None:
            acts.append(Action("protect", p.position_id, "posición propia sin stop", "alta"))
    for pid in sorted(set(local) - seen):
        acts.append(Action("close_local", pid, "cerrada en el servidor: buscar el deal", "baja"))
    for order_id, cid, _label in snap.pending:
        m = CID.fullmatch(cid or "")
        if m is None or m["cell"] != cell:
            acts.append(Action("alert", order_id, "orden pendiente ajena", "alta", close_only=True))
        elif int(m["epoch"]) < epoch:
            acts.append(Action("cancel", order_id, "orden de un turno anterior", "media"))
    if abs(snap.balance - local_balance) > 1_000_000:     # más de 0,01 en la divisa de la cuenta
        acts.append(Action("balance", 0, "saldo distinto: importar movimientos de caja", "media"))
    return acts

def _registry() -> dict[int, type[Message]]:
    """payloadType -> clase, leyendo el valor por defecto del campo payloadType de cada mensaje."""
    reg: dict[int, type[Message]] = {}

def frame(msg: Message, client_msg_id: str | None = None) -> bytes:
    """ProtoMessage{payloadType, payload, clientMsgId} precedido de su longitud (4 bytes, big-endian)."""
    env = cm.ProtoMessage(payloadType=payload_type(msg), payload=msg.SerializeToString())
    if client_msg_id:

    body = env.SerializeToString()
    return struct.pack(">I", len(body)) + body


class Bucket:
    """Cubo de fichas: `rate` por segundo con ráfaga `burst`."""

    def __init__(self, rate: float, burst: int) -> None:
        self.rate, self.burst = rate, burst
        self.tokens, self.t = float(burst), time.monotonic()

    async def take(self) -> None:
        while True:
            now = time.monotonic()
            self.tokens = min(self.burst, self.tokens + (now - self.t) * self.rate)
            self.t = now
            if self.tokens >= 1:
                self.tokens -= 1
                return
            await asyncio.sleep((1 - self.tokens) / self.rate)

    def __init__(self, env: str, client_id: str, client_secret: str,
                 on_event: Callable[[Message, int], None],
                 on_state: Callable[[str, str], None], host: str | None = None,
                 port: int = PORT, ssl_ctx: ssl.SSLContext | None = None) -> None:

        self._ssl = ssl_ctx or ssl.create_default_context()      # verificación TLS siempre activa
        self._id, self._secret = client_id, client_secret

        self._pending: dict[str, asyncio.Future[Message]] = {}
        self._ids = count(1)
        self._out: asyncio.Queue[bytes] = asyncio.Queue()
        self._general = Bucket(40, 40)                          # límite 50/s: margen del 20 %
        self._history = Bucket(4, 4)                            # límite 5/s
        self._blocked_until: dict[int, float] = {}              # payloadType -> monotonic
        self._last_rx = 0.0
        self._tasks: list[asyncio.Task[None]] = []
        self._writer: asyncio.StreamWriter | None = None

    # ---------- ciclo de vida ----------
    async def run_forever(self, on_ready: Callable[[CTraderClient], Awaitable[None]]) -> None:
        """Conecta, autentica, llama a on_ready (cuentas, suscripciones, conciliación) y vigila.
        Si algo cae, reconecta con espera exponencial y azar (1 s, 2 s, 4 s... hasta 60 s)."""
        attempt = 0
        while True:
            try:
                await self._connect()
                self._on_state("auth", "aplicación autenticada")
                await on_ready(self)
                self._on_state("ready", "")
                attempt = 0
                done, _ = await asyncio.wait(self._tasks, return_when=asyncio.FIRST_EXCEPTION)
                for t in done:
                    t.result()                                  # relanza lo que tiró la conexión
            except (OSError, asyncio.IncompleteReadError, TimeoutError, ConnectionLost,
                    ApiError) as e:
                self._on_state("down", repr(e)[:200])
            finally:
                await self._teardown()
            attempt += 1
            await asyncio.sleep(random.uniform(0, min(60.0, 2.0 ** attempt)))

    async def _connect(self) -> None:
        reader, self._writer = await asyncio.wait_for(
            asyncio.open_connection(self.host, self.port, ssl=self._ssl), timeout=10)
        self._last_rx = time.monotonic()
        self._tasks = [asyncio.create_task(c) for c in
                       (self._read_loop(reader), self._write_loop(), self._heartbeat_loop())]
        await self.request(om.ProtoOAApplicationAuthReq(
            clientId=self._id, clientSecret=self._secret), timeout=10)

    async def _teardown(self) -> None:
        for t in self._tasks:
            t.cancel()
        await asyncio.gather(*self._tasks, return_exceptions=True)
        self._tasks = []
        for fut in self._pending.values():
            if not fut.done():
                fut.set_exception(ConnectionLost("conexión perdida"))
        self._pending.clear()
        while not self._out.empty():
            self._out.get_nowait()                              # nada viejo sale por la conexión nueva
        if self._writer is not None:
            self._writer.close()
            self._writer = None

    # ---------- peticiones ----------
    async def request(self, msg: Message, timeout: float = 5.0) -> Message:
        pt = payload_type(msg)
        wait = self._blocked_until.get(pt, 0.0) - time.monotonic()
        if wait > 0:
            await asyncio.sleep(wait)                           # retryAfter de BLOCKED_PAYLOAD_TYPE
        await (self._history if pt in HISTORICAL else self._general).take()
        mid = f"m{next(self._ids)}"
        fut: asyncio.Future[Message] = asyncio.get_running_loop().create_future()
        self._pending[mid] = fut
        self._out.put_nowait(frame(msg, mid))
        try:
            res = await asyncio.wait_for(fut, timeout)
        finally:
            self._pending.pop(mid, None)
        if isinstance(res, (om.ProtoOAErrorRes, cm.ProtoErrorRes)):
            retry = int(getattr(res, "retryAfter", 0))
            if res.errorCode == "BLOCKED_PAYLOAD_TYPE" and retry:
                self._blocked_until[pt] = time.monotonic() + retry
            raise ApiError(res.errorCode, res.description, retry)
        if isinstance(res, om.ProtoOAOrderErrorEvent):
            raise ApiError(res.errorCode, res.description)
        return res

    async def send(self, msg: Message) -> str:
        """Para órdenes: respeta los límites, envía y no espera; lo que responda el servidor
        (ACCEPTED, FILLED, errores) llega al motor como evento y se anota en el diario."""
        await self._general.take()
        mid = f"m{next(self._ids)}"
        self._out.put_nowait(frame(msg, mid))
        return mid

    # ---------- tareas de la conexión ----------
    async def _read_loop(self, r: asyncio.StreamReader) -> None:
        while True:
            (n,) = struct.unpack(">I", await r.readexactly(4))
            if n > MAX_FRAME:
                raise ConnectionLost(f"trama de {n} bytes")
            env = cm.ProtoMessage.FromString(await r.readexactly(n))
            self._last_rx = time.monotonic()
            if env.payloadType == cmm.HEARTBEAT_EVENT:
                continue
            cls = REGISTRY.get(env.payloadType)
            if cls is None:
                continue                                        # tipo nuevo del servidor: se ignora
            msg = cls.FromString(env.payload)
            fut = self._pending.get(env.clientMsgId) if env.clientMsgId else None
            if fut is not None and not fut.done():
                fut.set_result(msg)
            if env.payloadType in EVENTS:
                self._on_event(msg, time.time_ns())             # el adaptador sí lee el reloj
            if env.payloadType == mo.PROTO_OA_CLIENT_DISCONNECT_EVENT:
                raise ConnectionLost("el servidor cerró la aplicación")

    async def _write_loop(self) -> None:
        assert self._writer is not None
        while True:
            data = await self._out.get()
            self._writer.write(data)
            await self._writer.drain()

    async def _heartbeat_loop(self) -> None:
        hb = frame(cm.ProtoHeartbeatEvent())
        while True:
            await asyncio.sleep(HEARTBEAT_EVERY)
            if time.monotonic() - self._last_rx > DEAD_AFTER:
                raise ConnectionLost("30 s sin datos del servidor")
            self._out.put_nowait(hb)

from pathlib import Path

from mym.ctrader.client import CTraderClient
from mym.ctrader.proto import OpenApiMessages_pb2 as om
from mym.ctrader.proto import OpenApiModelMessages_pb2 as mo


@dataclass(frozen=True, slots=True)
class Tokens:
    access: str
    refresh: str
    expires_at: int                   # Unix, segundos


class TokenStore:
    """Un fichero cifrado por cuenta (age). Solo renueva quien tiene el cerrojo."""

    def __init__(self, path: Path, holds_lease: callable, publish: callable) -> None:
        self.path, self.holds_lease, self.publish = path, holds_lease, publish

    async def fresh(self, c: CTraderClient) -> Tokens:
        t = self.load()
        if t.expires_at - time.time() > 7 * 86_400 or not self.holds_lease():
            return t                  # el access token dura unos 30 días: se renueva con 7 de margen
        res = await c.request(om.ProtoOARefreshTokenReq(refreshToken=t.refresh), timeout=15)
        new = Tokens(res.accessToken, res.refreshToken, int(time.time()) + res.expiresIn)
        self.save_atomic(new)         # primero guardar: el refresh token viejo ya no sirve
        self.publish(new)             # la reserva de esta célula necesita el token nuevo
        return new

    def save_atomic(self, t: Tokens) -> None:
        tmp = self.path.with_suffix(".tmp")
        tmp.write_bytes(encrypt(t))
        with open(tmp, "rb+") as f:
            os.fsync(f.fileno())
        os.replace(tmp, self.path)    # atómico: o el fichero viejo o el nuevo, nunca a medias

    def load(self) -> Tokens:
        return decrypt(self.path.read_bytes())

El diario y las proyecciones

El diario es la base de todo lo demás: la repetición exacta, el gemelo, la auditoría y el arranque tras una caída. Es un fichero de solo añadir, con cada registro encadenado al anterior por su hash, de modo que cualquier cambio o corte se nota.

"""Diario: registros encadenados con SHA-256 y escritos antes de actuar."""
from __future__ import annotations

import asyncio
import hashlib
import os
import struct
from pathlib import Path

import msgspec

ENC = msgspec.msgpack.Encoder(order="deterministic")
GENESIS = bytes(32)
HDR = struct.Struct(">I")


class JournalCorrupt(Exception):
    pass


class Journal:
    """Trama: [longitud u32][registro msgpack][sha256 del registro, 32 bytes].
    registro = (seq, ts, célula, turno, versión, cuerpo, hash_anterior)."""

    def __init__(self, dir_: Path, cell: str, version: str) -> None:
        self.dir, self.cell, self.version = dir_, cell, version
        dir_.mkdir(parents=True, exist_ok=True)
        self.seq, self.prev = recover(dir_)                  # verifica y recorta una cola rota
        self.epoch = 0
        self.f = open(dir_ / f"{self.seq + 1:012d}.seg", "ab", buffering=0)
        self._dirty = False
        self._lock = asyncio.Lock()

    def append(self, ev: msgspec.Struct) -> int:
        self.seq += 1
        rec = ENC.encode((self.seq, ev.ts, self.cell, self.epoch, self.version,
                          ENC.encode(ev), self.prev))
        h = hashlib.sha256(rec).digest()
        self.f.write(HDR.pack(len(rec)) + rec + h)          # sin búfer propio: llega al sistema
        self.prev, self._dirty = h, True
        return self.seq

    async def sync(self) -> None:
        """fsync agrupado: si ya hay uno en marcha, el siguiente cubre lo nuevo."""
        async with self._lock:
            if not self._dirty:
                return
            self._dirty = False
            await asyncio.to_thread(os.fsync, self.f.fileno())

    def rotate(self) -> Path:
        """Cierra el segmento (cada día a las 00:00 UTC o a los 256 MB) y abre otro."""
        old = Path(self.f.name)
        os.fsync(self.f.fileno())
        self.f.close()
        self.f = open(self.dir / f"{self.seq + 1:012d}.seg", "ab", buffering=0)
        return old                                           # se comprime y se envía al almacén


def recover(dir_: Path) -> tuple[int, bytes]:
    """Recorre todos los segmentos comprobando hashes, números y enlaces.
    Solo el final del último segmento puede estar a medio escribir: se recorta."""
    seq, prev = 0, GENESIS
    segs = sorted(dir_.glob("*.seg"))
    for i, seg in enumerate(segs):
        data, pos = seg.read_bytes(), 0
        while pos + 4 <= len(data):
            (n,) = HDR.unpack_from(data, pos)
            end = pos + 4 + n + 32
            if end > len(data):
                break                                        # registro incompleto
            rec, h = data[pos + 4: pos + 4 + n], data[pos + 4 + n: end]
            if hashlib.sha256(rec).digest() != h:
                raise JournalCorrupt(f"{seg.name}@{pos}: hash")
            s, *_rest, p = msgspec.msgpack.decode(rec)
            if s != seq + 1 or p != prev:
                raise JournalCorrupt(f"{seg.name}@{pos}: cadena rota")
            seq, prev, pos = s, h, end
        if pos < len(data):
            if i != len(segs) - 1:
                raise JournalCorrupt(f"{seg.name}@{pos}: hueco en un segmento cerrado")
            with open(seg, "r+b") as f:
                f.truncate(pos)
                os.fsync(f.fileno())
    return seq, prev

Probado: 1.010 registros en dos segmentos. Tras cortar 10 bytes del final, la recuperación volvió al registro 1.009 y el diario siguió escribiendo desde ahí. Un solo bit cambiado en medio del primer segmento se detectó en el acto. El fsync se hace en un hilo aparte con asyncio.to_thread, para no bloquear el bucle; como el bucle espera ese fsync antes de enviar, el orden se conserva.

Instantáneas

Cada pieza del núcleo sabe guardar su estado en un diccionario y restaurarlo. La instantánea es ese diccionario en msgpack, con el número de registro al que corresponde y su hash, en snapshots/{célula}/{seq}.snap. Se escribe cada hora y al parar. Para arrancar se carga la última válida y se repite el diario desde el registro siguiente. En la integración continua, una prueba toma una instantánea a mitad del día dorado, la restaura y comprueba que el resto del día sale idéntico.

from hypothesis import given
from hypothesis import strategies as st

from mym.core.domain import RiskState as S
from mym.portfolio.sizing import next_weight, to_volume, units_for_risk
from mym.risk.state import ORDER, Limits, Metrics, RiskMachine
from tests.factories import make_spec

steps = st.sampled_from([1, 100, 1_000, 100_000])


@given(units=st.floats(0, 1e8), step=steps, min_v=st.integers(1, 1_000_000))
def test_el_redondeo_nunca_sube_el_volumen(units: float, step: int, min_v: int) -> None:
    spec = make_spec(step_volume=step, min_volume=min_v, max_volume=10**12)
    v = to_volume(units, spec)
    assert v is None or (v <= units * 100 and v % step == 0 and v >= min_v)


@given(risk=st.integers(10**8, 10**12), dist=st.integers(1, 100_000), q2a=st.floats(0.01, 200))
def test_el_riesgo_real_no_pasa_del_pedido(risk: int, dist: int, q2a: float) -> None:
    spec = make_spec(step_volume=100, min_volume=100, max_volume=10**12)
    v = to_volume(units_for_risk(risk, dist, q2a), spec)
    if v is not None:
        real = v / 100 * dist / 100_000 * q2a * 10**8        # pérdida a stop, en 1e-8
        assert real <= risk * (1 + 1e-9)


@given(cur=st.floats(0, 1), prop=st.floats(-1, 3))
def test_jev_nunca_pasa_del_nominal_ni_sube_de_golpe(cur: float, prop: float) -> None:
    w = next_weight(cur, prop)
    assert 0 <= w <= 1 and w <= cur + 0.25 + 1e-12


pnl = st.floats(-0.05, 0.05)


@given(st.lists(pnl, min_size=1, max_size=200))
def test_dentro_del_dia_el_riesgo_nunca_se_relaja_solo(path: list[float]) -> None:
    m, worst_seen = RiskMachine(Limits()), S.NORMAL
    ok = dict(to_floor=0.1, drawdown=0.0, lease_ok=True, broker_ok=True, data_ok=True, paused=False)
    for p in path:
        s = m.step(Metrics(daily_pnl=p, **ok), day_rolled=False, manual_resume=False)
        assert ORDER.index(s) >= ORDER.index(worst_seen)      # nunca vuelve atrás sin día nuevo
        worst_seen = s
