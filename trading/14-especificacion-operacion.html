La operación, de principio a fin

Lo que rodea al núcleo: el guardián, el gemelo, el laboratorio, Jev, el plano de control, el relevo entre sedes, el despliegue, la seguridad, la vigilancia y las pruebas del sistema. Y el plan de trabajo, semana a semana, para construirlo con Claude Code.

En corto

  • El guardián es la segunda red: otro proceso con otra aplicación de la Open API y otro token, que mira la cuenta cada 5 segundos con límites más anchos que los del motor y solo puede cerrar y pausar.
  • El gemelo repite cada día lo que pasó cambiando una sola variable cada vez, así que la diferencia entre el backtest y la cuenta se reparte en spread, comisiones, swaps, deslizamiento, fallos, intervenciones, Jev y código, como pide el documento 11.
  • El relevo entre sedes se apoya en un cerrojo con caducidad en DynamoDB y un turno que va en cada orden. Probado en simulación: con cortes cortos la principal se detiene y vuelve; con cortes largos la reserva entra a los 45 segundos, y nunca hay dos a la vez.
  • Todo se construye en el orden y con las horas del documento 10: 155 horas para el mes de desarrollo, con cada tarea atada a un requisito y a una prueba, y Claude Code trabajando con permisos que le impiden tocar secretos, configuración de riesgo o cuentas reales.

"""El guardián: otro proceso, otra aplicación de la Open API y otro token. Mira la cuenta desde fuera."""
from __future__ import annotations

import asyncio
import time
from dataclasses import dataclass, field

CHECK_EVERY_S = 5.0


@dataclass(frozen=True, slots=True)
class GuardLimits:                     # más anchos que los del motor: el guardián es la segunda red
    no_sl_grace_s: float = 10.0        # G01: el motor tiene 2 s para poner el stop; el guardián espera 10
    daily_hard: float = 0.04           # G02: el motor para al 2,5 %; la firma corta al 5 %
    floor_hard: float = 0.01           # G03: a un 1 % del suelo total
    silent_warn_s: float = 60.0        # G04: motor sin latido
    silent_act_s: float = 300.0
    max_open_risk: float = 0.03        # G07: el motor no pasa del 2,5 %
    max_orders_per_min: int = 60       # G08: bucle desbocado


@dataclass(frozen=True, slots=True)
class Pos:
    position_id: int
    key: str
    side: int
    volume: int
    sl: int | None
    risk: int                          # pérdida si salta el stop, 1e-8 (0 si no hay stop)
    cell: str | None                   # de tradeData.comment
    epoch: int | None
    opened_ms: int


@dataclass(frozen=True, slots=True)
class Snapshot:                        # ProtoOAReconcileReq + TraderReq + UnrealizedPnL, en enteros
    initial: int
    equity: int
    day_ref: int                       # la referencia del día, calculada por el propio guardián
    total_floor: int
    positions: tuple[Pos, ...]
    orders_last_min: int


@dataclass(frozen=True, slots=True)
class EngineStatus:                    # del plano de control y del cerrojo, solo lectura
    cell: str
    epoch: int                         # turno vigente en el almacén del cerrojo
    epoch_since_ms: int                # desde cuándo
    last_heartbeat: float


@dataclass(frozen=True, slots=True)
class Finding:
    rule: str
    action: str                        # alert | pause | close_position | flatten
    target: int | None
    detail: str


def evaluate(s: Snapshot, e: EngineStatus, lim: GuardLimits, now: float,
             no_sl_since: dict[int, float]) -> list[Finding]:
    out: list[Finding] = []
    for p in s.positions:                                             # G01
        if p.sl is None:
            t0 = no_sl_since.setdefault(p.position_id, now)
            if now - t0 >= lim.no_sl_grace_s:
                out.append(Finding("G01", "close_position", p.position_id, "sin stop más de 10 s"))
        else:
            no_sl_since.pop(p.position_id, None)
    day = (s.equity - s.day_ref) / s.initial
    if day <= -lim.daily_hard:                                        # G02
        out.append(Finding("G02", "flatten", None, f"pérdida del día {day:.2%}"))
    if (s.equity - s.total_floor) / s.initial <= lim.floor_hard:      # G03
        out.append(Finding("G03", "flatten", None, "a un 1 % del suelo total"))
    silent = now - e.last_heartbeat                                   # G04
    if silent >= lim.silent_act_s and s.positions:
        out.append(Finding("G04", "pause", None, f"motor callado {silent:.0f} s con posiciones"))
    elif silent >= lim.silent_warn_s:
        out.append(Finding("G04", "alert", None, f"motor callado {silent:.0f} s"))
    for p in s.positions:
        if p.cell == e.cell and p.epoch is not None and p.epoch < e.epoch \
                and p.opened_ms > e.epoch_since_ms:                   # G05: zombi
            out.append(Finding("G05", "close_position", p.position_id,
                               f"abierta con el turno {p.epoch} después del relevo al {e.epoch}"))
        elif p.cell != e.cell:                                        # G06
            out.append(Finding("G06", "alert", p.position_id, "posición ajena"))
    open_risk = sum(p.risk for p in s.positions) / s.initial
    if open_risk > lim.max_open_risk:                                 # G07
        out.append(Finding("G07", "pause", None, f"riesgo abierto {open_risk:.2%}"))
    if s.orders_last_min > lim.max_orders_per_min:                    # G08
        out.append(Finding("G08", "pause", None, f"{s.orders_last_min} órdenes en un minuto"))
    return out


async def run(api: GuardApi, status: StatusSource, control: Control, notify: Notify,
              heartbeat: DeadMan, lim: GuardLimits = GuardLimits()) -> None:
    no_sl_since: dict[int, float] = {}
    while True:
        try:
            snap, eng = await api.snapshot(), await status.read()
            for f in evaluate(snap, eng, lim, time.time(), no_sl_since):
                await notify.send(f)                                  # siempre se avisa
                if f.action in ("pause", "flatten"):
                    await control.command(eng.cell, "pause", reason=f.rule)   # firmada con su llave
                if f.action == "close_position" and f.target is not None:
                    await api.close_position(f.target)
                if f.action == "flatten":
                    for p in snap.positions:
                        await api.close_position(p.position_id)
            await heartbeat.ping()                                    # «sigo vivo» a la vigilancia externa
        except Exception as exc:                                      # el guardián no se cae por un error
            await notify.send(Finding("G00", "alert", None, f"el guardián falló: {exc!r}"))
        await asyncio.sleep(CHECK_EVERY_S)

Corre en la misma máquina que la célula, en otro contenedor. Para vigilar al vigilante, el motor y el guardián envían un latido cada minuto a un servicio externo de «interruptor de hombre muerto». Si alguno calla tres minutos, el aviso llega al móvil aunque la máquina entera haya desaparecido.

"""El gemelo: repeticiones que cambian una sola cosa cada vez, y vigilancia del deslizamiento."""
from __future__ import annotations

from dataclasses import dataclass

# Cada repetición añade una sola variable a la anterior (documento 11). El orden es fijo
# para que dos meses se puedan comparar; con otro orden, los efectos cruzados se reparten distinto.
RUNS = (
    ("R0", "Gemelo a precio medio", "precios reales, todo encendido, sin fallos ni intervenciones, "
                                    "ejecución al precio medio y sin costes"),
    ("R1", "Spread", "+ ejecución al bid o al ask"),
    ("R2", "Comisiones", "+ comisiones del bróker"),
    ("R3", "Swaps", "+ swaps y días triples"),
    ("R4", "Fallos del sistema", "+ ventanas en que la célula no podía operar, sacadas del diario"),
    ("R5", "Intervenciones", "+ comandos manuales del diario"),
    ("R6", "Decisiones de Jev", "+ pesos reales de Jev"),
)


def attribution(pnl: dict[str, int], real: int, slippage: int) -> list[tuple[str, int]]:
    """pnl: resultado de cada repetición (1e-8). slippage: suma de (precio real - precio de R6)
    x lado x volumen de las ejecuciones emparejadas. Lo que queda sin explicar es código."""
    out = [(RUNS[0][1], pnl["R0"])]
    for (prev, _, _), (cur, name, _) in zip(RUNS, RUNS[1:], strict=False):
        out.append((name, pnl[cur] - pnl[prev]))
    out.append(("Deslizamiento", slippage))
    out.append(("Diferencias de código", real - pnl["R6"] - slippage))
    out.append(("Resultado de la cuenta", real))
    return out


@dataclass(frozen=True, slots=True)
class Fill:
    intent_seq: int                    # la decisión que la originó: mismo número en real y en gemelo
    strategy: str
    key: str
    side: int                          # +1 compra, -1 venta
    volume: int
    price: int                         # 1e-5
    ts: int


def match(real: list[Fill], twin: list[Fill]) -> tuple[list[tuple[Fill, Fill]], list[Fill], list[Fill]]:
    """Empareja por intención. Sin pareja en el gemelo: el sistema hizo algo que el modelo no;
    sin pareja en la realidad: una orden que no llegó a ejecutarse."""
    by_seq = {f.intent_seq: f for f in twin}
    pairs, only_real = [], []
    for f in real:
        t = by_seq.pop(f.intent_seq, None)
        if t is not None and (t.key, t.side) == (f.key, f.side):
            pairs.append((f, t))
        else:
            only_real.append(f)
    return pairs, only_real, sorted(by_seq.values(), key=lambda f: f.ts)


def slippage_points(pairs: list[tuple[Fill, Fill]]) -> list[float]:
    """Deslizamiento de cada ejecución en puntos de 1e-5, positivo = peor que el modelo."""
    return [float((r.price - t.price) * r.side) for r, t in pairs]


class Cusum:
    """CUSUM de Page sobre el deslizamiento tipificado (documento 11: k = 0,35 y h = 6)."""

    def __init__(self, mean: float, sd: float, k: float = 0.35, h: float = 6.0) -> None:
        self.mean, self.sd, self.k, self.h, self.s = mean, sd, k, h, 0.0

    def add(self, x: float) -> bool:
        z = (x - self.mean) / self.sd
        self.s = max(0.0, self.s + z - self.k)
        if self.s > self.h:
            self.s = 0.0                # tras la alarma, la suma vuelve a cero
            return True
        return False

El emparejamiento usa el número de registro de la intención, que es el mismo en la realidad y en el gemelo porque los dos corren el mismo código sobre las mismas entradas. El deslizamiento de cada ejecución, tipificado con su media y su desviación de los últimos tres meses, alimenta un CUSUM por estrategia con los parámetros del documento 11. Probado con los tres presets del documento 11: las partidas suman exactamente el resultado de la cuenta.

"""Bróker simulado: el mismo contrato que el adaptador de cTrader, con un modelo de ejecución explícito."""
from __future__ import annotations

from dataclasses import dataclass, field

NS = 1_000_000_000


@dataclass(frozen=True, slots=True)
class ExecModel:
    latency_ns: int = 150_000_000            # de la decisión al servidor: 150 ms
    slip_frac: float = 0.10                  # deslizamiento esperado: un 10 % de la horquilla
    commission_usd_per_million: float = 27.0 # por lado: unos 3 $ por lote en EURUSD (documento 11)
    limit_through: int = 1                   # un objetivo se ejecuta si el precio lo cruza 1 tick


@dataclass(slots=True)
class SimPos:
    position_id: int
    key: str
    side: int                                # +1 larga, -1 corta
    volume: int
    entry: int
    sl: int | None
    tp: int | None


@dataclass(slots=True)
class SimBroker:
    model: ExecModel
    pending: list[tuple[int, dict]] = field(default_factory=list)   # (listo_en_ns, orden)
    positions: dict[int, SimPos] = field(default_factory=dict)
    next_id: int = 1

    def submit(self, order: dict, now: int) -> None:
        """Una orden llega al servidor tras la latencia: se ejecuta con el primer tick posterior."""
        self.pending.append((now + self.model.latency_ns, order))

    def on_tick(self, key: str, bid: int, ask: int, ts: int, tick: int) -> list[dict]:
        events: list[dict] = []
        spread = ask - bid
        slip = round(self.model.slip_frac * spread)
        ready = [(t, o) for t, o in self.pending if t <= ts and o["key"] == key]
        for item in ready:
            self.pending.remove(item)
            o = item[1]
            if o["kind"] == "open":
                px = ask + slip if o["side"] > 0 else bid - slip       # compra al ask, vende al bid
                pid, self.next_id = self.next_id, self.next_id + 1
                sl = px - o["side"] * o["stop_distance"]
                tp = px + o["side"] * o["tp_distance"] if o.get("tp_distance") else None
                self.positions[pid] = SimPos(pid, key, o["side"], o["volume"], px, sl, tp)
                events.append({"type": "filled", "cid": o["cid"], "position_id": pid, "price": px,
                               "sl": sl, "ts": ts})
            elif o["kind"] == "close" and o["position_id"] in self.positions:
                p = self.positions.pop(o["position_id"])
                px = bid - slip if p.side > 0 else ask + slip
                events.append({"type": "closed", "position_id": p.position_id, "price": px,
                               "why": "close", "ts": ts})
        for p in [p for p in self.positions.values() if p.key == key]:
            mark = bid if p.side > 0 else ask                        # disparo TRADE: largos por bid
            if p.sl is not None and (mark - p.sl) * p.side <= 0:
                px = min(mark, p.sl) if p.side > 0 else max(mark, p.sl)   # con hueco, al precio del tick
                events.append(self._close(p, px, "stop", ts))
            elif p.tp is not None and (mark - p.tp) * p.side >= self.model.limit_through * tick:
                events.append(self._close(p, p.tp, "tp", ts))        # objetivo: solo si lo cruza
        return events

    def _close(self, p: SimPos, px: int, why: str, ts: int) -> dict:
        del self.positions[p.position_id]
        return {"type": "closed", "position_id": p.position_id, "price": px, "why": why, "ts": ts}

    def commission(self, volume: int, price_usd: float) -> float:
        """Comisión de un lado en USD: tarifa por millón de USD negociado (USD_PER_MILLION_USD)."""
        notional_usd = volume / 100 * price_usd
        return notional_usd / 1_000_000 * self.model.commission_usd_per_million

Probado: una compra no se ejecuta antes de que pase la latencia; con el bid justo en el objetivo no se cierra y con un tick más sí; y un hueco por encima del stop de una venta se ejecuta al precio del tick, peor que el stop.

"""Sharpe deflactado (Bailey y López de Prado, 2014), con el número de intentos del registro."""
from __future__ import annotations

import math
from statistics import NormalDist

EULER = 0.5772156649015329
N01 = NormalDist()


def expected_max_sharpe(n_trials: int, years: float) -> float:
    """Sharpe anual máximo esperado por azar entre n_trials intentos sin ventaja."""
    if n_trials < 2:
        return 0.0
    z = ((1 - EULER) * N01.inv_cdf(1 - 1 / n_trials)
         + EULER * N01.inv_cdf(1 - 1 / (n_trials * math.e)))
    return z / math.sqrt(years)                  # error típico del Sharpe anual ≈ 1 / √años


def deflated_sharpe(sr_annual: float, years: float, n_trials: int,
                    skew: float = 0.0, kurt: float = 3.0, days: int = 252) -> float:
    """Probabilidad de que el Sharpe verdadero supere al mejor esperado por azar."""
    sr = sr_annual / math.sqrt(days)
    sr0 = expected_max_sharpe(n_trials, years) / math.sqrt(days)
    n = years * days
    denom = math.sqrt(1 - skew * sr + (kurt - 1) / 4 * sr * sr)
    return N01.cdf((sr - sr0) * math.sqrt(n - 1) / denom)

Es la fórmula del documento 11 con el número de intentos que da el registro. Con un Sharpe de 1,5 en 8 años y 50 intentos devuelve 0,975, el 98 % del calculador de aquel documento; con 1.000 intentos, 0,84. La regla: nada pasa a incubación por debajo de 0,95.

def majority(votes: list[dict]) -> dict[str, dict]:
    """Por estrategia, el estado que eligen al menos dos de tres. Sin mayoría, no hay decisión."""
    out: dict[str, dict] = {}
    for s in STRATEGIES:
        picks = [d for v in votes for d in v["decisiones"] if d["estrategia"] == s]
        if not picks:
            continue
        state, n = Counter(d["estado"] for d in picks).most_common(1)[0]
        if n >= 2:
            out[s] = next(d for d in picks if d["estado"] == state)
    return out

class Verdict:
    strategy: str
    action: str                          # apply | pending | wait | reject | shadow
    state: str
    why: str


def validate(dec: dict[str, dict], parte: dict, current: dict[str, str], days_in_state: dict[str, int],
             changes_this_week: int, risk_stopped: set[str], confirmed_twice: set[str],
             cfg: JevCfg) -> list[Verdict]:
    keys = set(parte.get("lecturas", {})) | {f"estrategias.{s}" for s in parte.get("estrategias", {})}
    out: list[Verdict] = []
    for s, d in sorted(dec.items()):
        new, old = d["estado"], current[s]
        if new == old:
            continue
        up = WEIGHT[new] > WEIGHT[old]
        cited = set(d["lecturas_citadas"])
        if not cited or not cited <= keys:
            out.append(Verdict(s, "reject", new, "cita lecturas que no están en el parte"))
        elif up and s in risk_stopped:
            out.append(Verdict(s, "reject", new, "la paró el riesgo: Jev no la reactiva"))
        elif days_in_state[s] < cfg.min_days_in_state:
            out.append(Verdict(s, "reject", new, "tiempo mínimo en el estado no cumplido"))
        elif changes_this_week >= cfg.max_changes_per_week:
            out.append(Verdict(s, "reject", new, "máximo de cambios de la semana"))
        elif cfg.phase == 1:
            out.append(Verdict(s, "shadow", new, "fase 1: se registra y no se aplica"))
        elif up and cfg.phase == 2:
            out.append(Verdict(s, "reject", new, "fase 2: solo puede apagar o dejar en base"))
        elif up and cfg.phase == 3:
            out.append(Verdict(s, "pending", new, "fase 3: encender o subir necesita tu aprobación"))
        elif up and s not in confirmed_twice:
            out.append(Verdict(s, "wait", new, "fase 4: se aplica si el próximo parte lo confirma"))
        else:
            out.append(Verdict(s, "apply", new, d["motivo"]))
            changes_this_week += 1
    return out

from __future__ import annotations

import base64
import json
import time

from cryptography.exceptions import InvalidSignature
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey, Ed25519PublicKey

ROLES = {                                          # qué puede pedir cada tipo de llave
    "operator": {"pause", "resume_request", "resume_confirm", "flatten", "reduce", "weights"},
    "mobile": {"pause", "flatten"},                # el móvil solo puede frenar
    "guardian": {"pause"},
    "jev": {"weights"},
}
REDUCE_ONLY = {"reduce": ("factor", 1.0), "weights": ("max", 1.0)}   # nunca por encima de 1


def canonical(cmd: dict) -> bytes:
    return json.dumps(cmd, sort_keys=True, separators=(",", ":"), ensure_ascii=False).encode()


def sign(cmd: dict, key: Ed25519PrivateKey) -> str:
    return base64.b64encode(key.sign(canonical(cmd))).decode()


class NonceCache:
    def __init__(self) -> None:
        self.seen: dict[str, float] = {}

    def add(self, nonce: str, expires_at: float, now: float) -> bool:
        self.seen = {n: t for n, t in self.seen.items() if t > now}   # olvida los caducados
        if nonce in self.seen:
            return False
        self.seen[nonce] = expires_at
        return True


def verify(cmd: dict, sig: str, key_id: str, keys: dict[str, tuple[str, Ed25519PublicKey]],
           cell: str, seen: NonceCache, now: float | None = None) -> str | None:
    """None si el comando vale; si no, el motivo. La célula lo comprueba aunque ya lo
    hiciera el plano de control: un plano de control comprometido no puede fabricar órdenes."""
    now = time.time() if now is None else now
    if key_id not in keys:
        return "llave desconocida"
    role, pk = keys[key_id]
    try:
        pk.verify(base64.b64decode(sig), canonical(cmd))
    except (InvalidSignature, ValueError):
        return "firma no válida"
    if cmd.get("cell") != cell:
        return "es para otra célula"
    if not (cmd["issued_at"] <= now + 5 and now <= cmd["expires_at"] <= cmd["issued_at"] + 120):
        return "fuera de plazo"
    if cmd["name"] not in ROLES[role]:
        return f"una llave {role} no puede pedir {cmd['name']}"
    if cmd["name"] in REDUCE_ONLY:
        field, cap = REDUCE_ONLY[cmd["name"]]
        vals = cmd["args"].values() if cmd["name"] == "weights" else [cmd["args"][field]]
        if any(not 0.0 <= float(v) <= cap for v in vals):
            return "desde fuera solo se puede reducir"
    if not seen.add(cmd["nonce"], cmd["expires_at"], now):
        return "repetido"
    return None

"""Cerrojo con caducidad y turno. Solo opera quien lo tiene, y el turno va en cada orden."""
from __future__ import annotations

from dataclasses import dataclass
from decimal import Decimal
from typing import Protocol

TTL_S = 30.0          # caducidad en el almacén
RENEW_S = 10.0        # la principal renueva cada 10 s
MARGIN_S = 10.0       # R02: sin 10 s de margen no se opera -> autocensura a los 20 s
QUIET_S = 10.0        # la reserva espera 10 s más tras la caducidad


class Store(Protocol):
    def read(self, cell: str) -> dict | None: ...
    def acquire(self, cell: str, me: str, prev_epoch: int, expires_at: float, cutoff: float) -> bool: ...
    def renew(self, cell: str, me: str, epoch: int, expires_at: float) -> bool: ...


@dataclass(slots=True)
class Lease:
    store: Store
    cell: str
    me: str                           # "c01@lon-a"
    epoch: int = 0
    expires_local: float = 0.0        # caducidad según nuestra última renovación buena

    def try_acquire(self, now: float) -> bool:
        item = self.store.read(self.cell)
        prev = int(item["epoch"]) if item else 0
        if item and float(item["expires_at"]) + QUIET_S > now:
            return False              # vigente, o caducado hace menos de 10 s
        if not self.store.acquire(self.cell, self.me, prev, now + TTL_S, now - QUIET_S):
            return False              # otro ganó la carrera o la principal renovó a tiempo
        self.epoch, self.expires_local = prev + 1, now + TTL_S
        return True

    def renew(self, now: float) -> bool:
        """`now` es la hora de ANTES de enviar la petición: si tarda, el margen se come el retraso."""
        ok = self.store.renew(self.cell, self.me, self.epoch, now + TTL_S)
        self.expires_local = now + TTL_S if ok else 0.0     # si otro lo tiene, se para ya
        return ok

    def margin(self, now: float) -> float:
        return self.expires_local - now

    def may_trade(self, now: float) -> bool:
        return self.margin(now) >= MARGIN_S


class DynamoStore:
    """DynamoDB con escrituras condicionales. Tabla: clave de partición `cell` (texto)."""

    def __init__(self, table: object) -> None:
        self.t = table                                    # boto3.resource("dynamodb").Table(...)

    def read(self, cell: str) -> dict | None:
        return self.t.get_item(Key={"cell": cell}, ConsistentRead=True).get("Item")

    def acquire(self, cell: str, me: str, prev_epoch: int, expires_at: float, cutoff: float) -> bool:
        return self._cond(lambda: self.t.put_item(
            Item={"cell": cell, "owner": me, "epoch": prev_epoch + 1,
                  "expires_at": Decimal(str(round(expires_at, 3)))},
            ConditionExpression="attribute_not_exists(#c) OR (#e = :prev AND #x < :cutoff)",
            ExpressionAttributeNames={"#c": "cell", "#e": "epoch", "#x": "expires_at"},
            ExpressionAttributeValues={":prev": prev_epoch, ":cutoff": Decimal(str(round(cutoff, 3)))}))

    def renew(self, cell: str, me: str, epoch: int, expires_at: float) -> bool:
        return self._cond(lambda: self.t.update_item(
            Key={"cell": cell},
            UpdateExpression="SET #x = :exp",
            ConditionExpression="#o = :me AND #e = :e",
            ExpressionAttributeNames={"#o": "owner", "#e": "epoch", "#x": "expires_at"},
            ExpressionAttributeValues={":exp": Decimal(str(round(expires_at, 3))), ":me": me,
                                       ":e": epoch}))

    @staticmethod
    def _cond(call: object) -> bool:
        from botocore.exceptions import ClientError
        try:
            call()                                        # type: ignore[operator]
            return True
        except ClientError as e:
            if e.response["Error"]["Code"] == "ConditionalCheckFailedException":
                return False                              # la condición no se cumplió
            raise                                         # red u otro error: se reintenta fuera

La reserva no lo necesita para operar con seguridad, porque concilia con el bróker; lo usa para continuar la historia y para arrancar con los indicadores calientes.

Hasta 2027, la reserva no toma el cerrojo sola: lo toma cuando tú ejecutas el manual de relevo. El código es el mismo; solo cambia que la comprobación automática está desactivada en la configuración hasta haber practicado el relevo manual varias veces.

Cómo sale una versión

  1. Cambio revisadomake check en verde en la integración continua y tu revisión del cambio.
  2. Imagen firmadaAl entrar en la rama principal se construye la imagen, se sube al registro y se firma con cosign. El despliegue verifica la firma y usa el digest, nunca una etiqueta.
  3. Demo, 24 horasLa versión corre un día en la célula de demo. La repetición exacta de ese día debe coincidir y el gemelo no debe mostrar diferencias de código.
  4. Real, con el mercado cerradoEl sábado por la mañana, o entre semana solo sin posiciones de REV-M5 ni de MOM-US500 abiertas. La célula para ordenadamente: instantánea, segmento cerrado, cerrojo soltado.
  5. ComprobaciónVersión y hash de configuración esperados en el panel, conciliación limpia y riesgo en NORMAL.
  6. Vuelta atrásEl digest anterior sigue en releases/c01.digest del historial: se despliega igual, en un minuto.

    type filter hook output priority 0; policy drop;
    ct state established,related accept

    oifname "wg0" accept
    ip daddr @trading tcp dport 5035 accept      # cTrader Open API
    tcp dport 443 accept                         # AWS (cerrojo y almacén), registro de imágenes
    udp dport { 53, 123, 51820 } accept          # DNS, hora y túnel
    tcp dport 4460 accept                        # NTS-KE
  }

Manuales

Manuales de incidentes

Cuando algo falla a las tres de la mañana no se piensa: se sigue un manual. Estos ocho cubren lo que puede pasar, y cada uno se practica en demo antes de necesitarlo.

Crítico

La célula no da señales

  1. Mira el panel y la vigilancia externa: ¿cae la célula o toda la máquina?
  2. Si la máquina responde por el túnel, revisa docker compose ps y los registros del motor.
  3. Si no responde, abre la consola del proveedor.
  4. Mientras tanto protegen los stops del servidor. Comprueba en cTrader que todas las posiciones los tienen; si alguna no, ciérrala desde allí.
  5. Si en 15 minutos no vuelve, relevo manual.
Procedimiento

Relevo manual en cinco pasos

  1. Asegúrate de que la principal no opera: en el panel o apagándola desde su proveedor.
  2. En la reserva, toma el cerrojo: mym lease take --cell c01, que sube el turno.
  3. Arranca la célula de la reserva: docker compose up -d.
  4. Espera la conciliación limpia y el estado NORMAL en el panel.
  5. Anota la incidencia. Cuando la principal vuelva, se quedará de reserva sola, porque su turno es viejo.
Aviso

Pérdida del día cerca del límite

  1. El motor ya actúa: comprueba en qué estado está y por qué.
  2. Revisa si hay posiciones sin stop, muy correlacionadas o expuestas a una noticia inminente.
  3. Si lo ves claro, cierra todo con la llave del móvil. Nunca reanudes el mismo día.
  4. Llévalo a la revisión semanal con la cascada del gemelo.
Crítico

Diferencia grave con el bróker

  1. Lee la diferencia en el panel: clase, posición y acción tomada.
  2. Si hay una posición ajena y no fuiste tú: cambia la contraseña de cTrader ID, revoca los tokens y cierra todo.
  3. Si fue una ejecución que no llegó al diario, la adopción es automática: comprueba su stop.
  4. Abre una incidencia con el diario del día.
Aviso

Token revocado o caducado

  1. La célula está en SOLO_CERRAR y los stops protegen.
  2. Vuelve a autorizar la aplicación en cTrader ID con el flujo de OAuth.
  3. Guarda los tokens nuevos cifrados con sops y despliega a la célula y a su reserva.
  4. Comprueba la conciliación y el estado NORMAL.
Crítico

Proveedor caído

  1. Confirma en la página de estado del proveedor que no es solo tu máquina.
  2. Relevo manual a la reserva del otro proveedor.
  3. Vigila la primera hora con atención.
  4. Cuando vuelva el proveedor, recupera la principal como nueva reserva y decide si la devuelves.
Crítico

Stop-out o aviso de la firma

  1. La célula queda en PARADA: no la reanudes.
  2. Guarda el diario, las capturas y los correos.
  3. Contacta con la firma y relee su fichero de reglas.
  4. Informe de incidencia antes de cualquier otra operación en esa firma.
Crítico

Sospecha de intrusión

  1. Cierra todo con la llave del móvil y revoca los tokens desde cTrader ID.
  2. Rota las llaves de age, WireGuard y comandos.
  3. Fabrica máquinas nuevas con la receta; no reutilices las sospechosas.
  4. Revisa los registros de accesos y de comandos, y recupera los diarios del almacén bloqueado.

Cómo lo programaría con Claude Code

  1. Una tarea, un día como muchoCada tarea de las tablas es un encargo con su identificador, los requisitos que cita y su «terminada cuando». Las secciones de los documentos 13 y 14 van en docs/spec/, dentro del repositorio, para que Claude Code las lea.
  2. Primero el planClaude Code propone qué ficheros toca y qué pruebas escribe; tú lo apruebas antes de que escriba código.
  3. Pruebas antes que códigoEscribe las pruebas, las ejecuta y comprueba que fallan; después, lo mínimo para que pasen.
  4. Todo en verdemake check entero. Un gancho formatea cada fichero que edita.
  5. Segunda miradaUn subagente de revisión, con permisos de solo lectura, compara el cambio con los requisitos que cita la tarea y lista lo que falte.
  6. Tú decidesRevisas el cambio y lo fusionas. Nada llega a real sin pasar por la demo y sin tu firma.

# mym · instrucciones para Claude Code

Sistema de trading por células. Especificación: documentos 12, 13 y 14 de «Máquinas y mercados».
Python 3.13, uv, un paquete `mym` en src/. Todo cambio cita el requisito que cumple (NUC-01, R07...).

## No se rompe nunca
- Los requisitos NUC-01 a NUC-08 del documento 13. Si una tarea choca con uno, para y pregunta.
- En src/mym/{core,strategies,portfolio,risk,oms}: ni reloj del sistema, ni azar, ni E/S.
- Precios, volúmenes y dinero son enteros de mym.core.units. Nada de float fuera de indicadores.
- No toques config/firms/, config/cells/ ni los límites de riesgo si la tarea no lo pide por escrito.
- Ninguna dependencia nueva sin una decisión en docs/adr/.
- Nada contra cuentas reales. Solo demo, con credenciales de demo.
- Ningún backtest fuera de `mym lab run`: todos quedan en el registro de intentos.

## Cómo trabajar
1. Lee la tarea y los requisitos que cita.
2. Escribe primero las pruebas que fallan; después, lo mínimo para que pasen.
3. `make check` entero en verde antes de proponer nada.
4. En la descripción del cambio: qué requisito cumple, qué probaste y qué no.
5. Si algo del bróker no está claro, no lo supongas: añádelo a la lista de preguntas para la demo.

## Comandos
- `make check` (menos de 2 minutos) · `make slow` · `make proto`
- `uv run mym lab run --strategy REV-M5 --window 2019-01-01:2024-12-31`
- `uv run mym replay --cell c01 --date 2026-11-18 --exact`
- `uv run mym journal verify --cell c01`
