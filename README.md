## Cómo abrirlos

Cada archivo es autónomo: descárgalo y ábrelo en un navegador. Solo necesita conexión para cargar las tipografías de Google Fonts; sin ella se ven con tipografías del sistema.

Los gráficos, calculadoras y simuladores funcionan en el propio navegador. Las simulaciones usan datos aleatorios y sirven para ilustrar ideas; las cifras reales proceden de las fuentes citadas al final de cada documento.

## Aviso

Contenido educativo. No es asesoramiento financiero ni una recomendación de inversión.
